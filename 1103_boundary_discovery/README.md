## 工作方式

协调者根据当前证据唤醒研究角色：寻找解释边界、跨领域检索、构造假说、执行实验、审查竞争解释。角色可以重复调用，失败后允许修订或换题。研究者可以写代码、下载公开数据、检索论文和修改观察方式；没有预先指定缺失变量或正确公式。

`src/runtime.py` 负责真实 GPT-6 Luna 调用、独立工作目录、事件日志、失败恢复和输入输出记录。上层 `src/discover.py` 根据协调者的决策分配下一步工作。已有 Codex 登录用于模型调用，不在项目保存凭据。

## 目录

- `docs/`：结构、运行协议和操作说明。
- `bootstrap/`：本次选题、资料可得性和先行文献检查。
- `src/`：可复用运行器与协调循环。
- `runs/`：每次运行的任务、代码、数据、模型记录与结论。
- `INITIAL_RESULTS.md`：本次真实运行的结果、被否定的解释与系统问题。
