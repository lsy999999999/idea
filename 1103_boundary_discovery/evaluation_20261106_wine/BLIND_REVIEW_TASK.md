# 候选文本独立评阅

只读本文件与同目录 `BLIND_CARDS.json`。不要读取其他文件、映射键、运行目录或历史报告。不要检索文献；这项评阅衡量文本中的研究内容，文献原创性由另一个检查处理。不要因缺数据、实验、证明或实现而扣分。

逐条评阅所有卡片。三个维度分别给 0–3 或 unknown，不给总分或加权平均：

- 研究价值：0=无研究对象；1=已有任务的常规分析/质量检查；2=明确科学不确定性且区分结果有意义；3=影响多个现象或理论选择的关键问题。
- 概念内容：0=空泛愿望；1=操作定义或熟悉方法组合；2=明确的新关系、机制或必要区分；3=可迁移解释结构，并说明成立条件。“新”在这里指文本相对于通用任务的概念增量，不是文献未做过。
- 可派生后果：0=没有后续研究内容；1=下一步实现/验证清单；2=核心概念推出两个可区分的研究后果；3=不同条件或场景下成组不同后果。普通数据检查、实施步骤和限制清单不算研究后果。

每个分数绑定该卡片文本的精确引句及理由；引句必须逐字出现，JSON 字段值中的原文也可用。未写出的机制、预测或条件不替作者补写。长度、术语、谨慎语气和即时可实现性不加分。不同表述的同一问题分清；指出研究设计中的循环定义或明显逻辑错误。

写 `BLIND_REVIEW.json`，字段 `reviews:[{id,research_value:{score,quote,reason},conceptual_content:{score,quote,reason},generativity:{score,quote,reason},core_content,obvious_problem}]`；另写 `BLIND_REVIEW.md` 简述最有内容的概念与重复/薄弱问题。不推断文本来源、不建立来源组排序，不判断全世界原创性。文件写在本目录，完成后不要再改写。
