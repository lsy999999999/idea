# 检查报告

完成了三项候选的两项规定检查。独立检索使用 OpenAlex Works API，按 problem、mechanism、contribution 各执行一次预先限定 2009 年末的探索查询；原始 JSON 响应保存在 `snapshots/`。命中记录有噪声，尚未完成 30–50 篇候选筛选、8–10 篇摘要核读或 3–5 篇全文深比，因此不能作无近邻结论。历史参照沿用控制端 2010-01-01（exclusive），origin_1 暴露状态沿用输入的 hidden。

## 结果

- `idea_distance_transition`：二维鱼群/集体运动轨迹研究是非常相近的方向。检索到 2004 年鱼群观测与理论比较、2009 年动物群体集体运动建模；对“分位状态后10帧有向距离变化并报告个体位移”的精确覆盖仍未核实。数学定义无明显错误，分位数和滞后被明示为操作定义。
- `idea_history_prediction`：历史轨迹状态及集体运动预测属于非常相近方向。共同有效样本、目标对齐和时间留出是可行比较约束；所给检索尚未核实此前10帧平均相对位移是否已作为同一基线增量被测试。预测改善不被解释为互动/记忆，逻辑范围适当。
- `idea_direction_similarity`：群体运动方向一致性是非常相近方向。点积除以模长乘积是标准余弦相似度，明确排除零位移并描述图像平面方向，无明显数学错误。是否已有工作采用完全相同的两标签逐帧定义、阈值敏感性处理，证据不足。

2004/2009作品只以 OpenAlex 记录和摘要索引证据用于宽方向判断；没有将书目元数据当作具体方法覆盖证据。2017 origin_1 属于 cutoff 后文献，仅作为隐藏来源重发现比较对象，不具备历史否定资格。所有主张均保留；继续探索前应针对每个精确操作定义核读最接近论文全文。
