# 补学后交流

两位同伴把 NST 的方法层补得更具体了。生态学同伴核对 Renes 等报告：以丰度加权 robust Aitchison 距离为输入，使用 tNST、PF 零模型和 999 次随机化；四个重复构成六个共享重复的 pair，论文在模型中处理其非独立性。物理学同伴从 NST 手册补充，PF 分别约束物种出现频率和样本丰富度；固定观测距离而改变零分布，可能改变相对解释。这是对原有“NST 是模型依赖推断”认识的细化，不是纠错。两人都保留 tNST 公式、PF 精确实现及阈值校准等缺口。

因此，共同对象从“群落状态/历史效应”改为分层关系图：扰动历史连接到丰富度、组成、重复间离散度等各自的观测轨迹；组成经指定距离和 PF 参照后另形成 NST 推断节点；测序检出过程影响可见的 ASV 丰富度。每条轨迹支持的恢复描述仍须说明响应量、参照与时间窗，且不等于功能恢复或对下一次脉冲的预测充分性。

**问题变化**：我们现在追问每种轨迹具体支持哪一层描述；轨迹冲突能否定位到响应对象、采样/检出过程、NST 的模型参照，或预测目标遗漏的状态。没有解决真实组装变化与检测阈值的相对贡献，也没有比较替代零模型或检验未来响应预测；这些分支保留开放。
