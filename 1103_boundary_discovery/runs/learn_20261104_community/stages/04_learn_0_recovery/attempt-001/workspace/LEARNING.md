# NST 学习记录（恢复尝试）

## 缺口与来源

交流后识别的缺口是：Renes 等实际 NST 分析的输入、零模型和推断边界是什么？我直接复读了项目归档的论文全文提取文本中 NST 方法段和补充表说明（来源 URL: https://doi.org/10.1111/1462-2920.70430）。文本称其使用 robust Aitchison 距离得到的丰度加权群落不相似度，与指定零模型下的不相似度分布比较；使用 NST 包 3.1.10 的 tNST、Proportional-Fixed (PF) 零模型和 999 次随机化。补充表说明每个处理×时点有 4 个重复，其 6 个独特重复 pair 的距离/NST 混合模型以 pair ID `comp` 处理 pair 间非独立性。

通用概念参考 Ning et al. (2019), https://doi.org/10.1073/pnas.1904623116。上次尝试取得的 PNAS 与 Europe PMC 页面实际是 Cloudflare challenge HTML，不能当全文或摘要证据；本次不重复扩展检索。对通用 NST 定义仅依据恢复材料记录的 Crossref 摘要：它是比较观测与零模型的归一化相对随机性指标，可依赖相似度和零模型选择；未掌握原论文的完整推导。

## 学习例子与理解变化

假设 4 个重复 A、B、C、D，所有无序不同 pair 为 AB、AC、AD、BC、BD、CD，因此 `4×3/2=6`。这些 pair 不是 6 个独立群落：例如 A 同时进入 AB、AC、AD。论文将 pair ID 纳入随机效应，正回应这种共享样本导致的相关性。此为结构学习计算，不计算 NST，也非研究数据复算。

我此前容易将 NST 高值看成对“随机性占优”的直接观测。现在区分：群落组成测量 -> pairwise 距离 -> 相对 PF 随机化距离分布的 NST 推断。结果是依赖指定距离/零模型/数据结构的推断量，不等于生态动力学状态或随机机制本身。案例报告 NST 大多超过 0.5 是已发表结果，不是本轮发现。
