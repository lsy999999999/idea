# 保留的分支与未决问题

- **真实组装/组成变化**：历史可能与成员筛选、耐受性或组装过程变化相关；资料不能唯一识别机制。
- **测序检出阈值**：低丰度 ASV 越过检测限可能造成表观丰富度变化；可与真实组成变化并存，当前不能估计相对贡献。
- **NST 模型参照敏感性**：案例方法报告使用 robust Aitchison 距离、PF 零模型和 999 次随机化；尚未比较替代零模型或分组设置。tNST 完整公式、PF 精确实现与阈值校准仍未厘清。
- **预测状态充分性**：未测试丰富度、组成或组合观测能否预测下一次扰动响应；物理研究者的隐藏状态玩具例仅说明逻辑可能性，不是案例测量或生物学发现。
- **功能恢复**：案例没有直接功能测量，因此丰富度、组成或 NST 轨迹都不能单独支持功能恢复结论。
- **不同稳定性维度**：若后续使用“恢复”，仍须标明响应量、参照和时间窗；某个投影的回归不能替代完整动力学状态回归。

本轮没有把这些分支拆成独立候选，因为交流将它们作为同一轨迹分歧问题中待定位、待区分的层次；没有进行方向查重或可行性筛选。
