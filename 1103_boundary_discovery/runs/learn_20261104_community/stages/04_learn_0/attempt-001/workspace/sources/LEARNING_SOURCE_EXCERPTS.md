Verbatim relevant figure-caption text: “Normalized stochasticity ratio (NST; based on null modelling of pairwise Aitchison distances) over time for each treatment”.

Verbatim relevant result text: “Results from the null model analysis showed that NST values exceeded 0.5 across all treatments and at nearly all time points.”

Verbatim relevant method text: “NST compares the observed community dissimilarity, abundance-weighted Aitchison distances computed with the robust Aitchison method, to a distribution of dissimilarities generated under a specified null model. We used tNST in package NST (version 3.1.10) with a Proportional-Fixed (PF) null model and 999 randomizations. NST values range from 0 to 1 and reflect the relative balance between deterministic and stochastic assembly processes, with lower values indicating a stronger relative contribution of deterministic processes and higher values indicating a stronger relative contribution of stochastic processes.”

Verbatim relevant design text: “There were 3 × 2 treatment groups, with four replicates each (24 vessels in total...)”.

Verbatim supplementary-table description: “For pairwise Aitchison distance and NST models, the random effect (1|comp) accounts for non-independence among replicate pairs within each treatment × time combination. Here, comp identifies each unique replicate pair used to calculate pairwise community distances (e.g., Replicate 1–Replicate 2, Replicate 1–Replicate 3, Replicate 2–Replicate 3).”

The extracted text states the selected PF null model and randomization count. It does not, in the method passage available here, spell out the biological interpretation of the constraints PF preserves; the complete archived text remains the source record.
