# 回到共同问题：预测与机制识别

## 共同对象

在各自明确的细胞来源、训练历史、取样/培养流程和后续挑战下测得的群体功能终点。群体读数可以作为预测对象；潜在的细胞内响应、亚群有效权重、存活/选择和细胞间作用则属于需要额外信息才能辨识的微观来源。原论文的 LPS 炎症终点与胞内细菌利福平存活来自不同实验支路，继续分开。

## 对线性混合例子的回应

教学公式 `总体读数 = Σ(亚群有效权重 × 亚群读数)` 适合说明：均值通常不能唯一确定其组成。它作为测量近似，需要有效权重明确、各贡献近似可加、检测近似线性，且差异存活与强细胞间作用可忽略或另行建模。

免疫学者指出真实培养读数还可能受每细胞分泌量、细胞数、存活、贴壁选择、旁分泌/细胞接触作用和归一化影响。这些因素可能让“有效权重”不等于细胞比例，或让读数不再是简单加权和。因此例子没有拟合目标论文的 NO/TNF-α 数据，也不说明该论文的亚群组成发生了改变。

## 修订后的问题

对金黄色葡萄球菌研究中的每条实验支路，能否在明确协议下先评估群体读数对预先指定终点的预测价值？若要进一步把预测关联解释为细胞内在训练、亚群权重、存活或细胞间作用，分别还缺哪些配对测量和测量模型条件？若缺少这些信息，结论应停留在群体经验描述。

这把两个任务并列保留：群体层面的预测可不依赖微观机制完全可识别；机制识别则不能由预测成功自动推出。宿主炎症响应和胞内细菌耐受仍是不同支路。

## 分支与未决项

- **群体预测：** 指定取样/培养与挑战后，哪些群体观测能预测一个明确的功能终点？当前未做预测评估。
- **混合模型条件：** 目标检测是否接近线性、贡献是否可加、有效权重如何定义？未知。
- **机制识别：** 哪些细胞分辨、组成、存活或互作信息能分开潜在来源？最小充分信息组合未知。
- **宿主-病原关系：** 如何配对宿主 LPS 炎症与胞内细菌药物存活终点，而不把不同实验流程合并？保持开放。
