# 初始理解：重复刺激与状态

我把“状态”看作相对于一个指定后续响应的问题：哪些变量足以描述系统对下一次挑战的反应？免疫论文报告初次金黄色葡萄球菌感染后，分离的腹腔巨噬细胞静置7天再受LPS刺激时，NO和TNF-α响应较高；研究还报告继发感染时细菌利福平耐受变化。这些是不同测量终点，不能由其中一个读数代替完整免疫状态。

例如，若NO/TNF-α恢复到对照水平，尚不能推出细菌耐受或其他挑战下的功能也恢复。相同读数但细胞群组成不同，是帮助理解“观测不充分”的反事实例子，不是论文报告的观察。旧笔记来自微生物群落案例；本次只借用状态与观测充分性的提问方式，不迁移NST、ASV或生态机制。

我尚不能判断该研究的响应变化由细胞内重编程、群体组成/存活差异还是两者共同造成。要问免疫学同伴：现有实验测量实际区分了哪些可能性？

长期知识实际复用：`state_memory_observability`（来源任务 `learn_20261104_community`），用于把单项观测与对未来指定响应的状态充分性分开；适用范围限制见 `result.json` 的 `memory_use`。
