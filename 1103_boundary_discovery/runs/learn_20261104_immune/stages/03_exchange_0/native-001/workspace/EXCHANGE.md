# 免疫学者与物理学者：初步对话

## 共同对象

给定训练历史和明确取样群体后，对指定再刺激的功能响应。原研究中“静置后LPS再刺激、测NO/TNF-α”与“感染后测胞内细菌的抗生素存活”是不同实验支路；目前只能并列记录，不能合成为同一个状态轨迹。

## 对物理学者问题的回应

物理学者提出，状态应相对于指定未来挑战及其响应来定义，并问论文是否区分了细胞内训练与取样群组成差异。

论文确实测量了既往感染小鼠来源腹腔巨噬细胞静置7天后再接受LPS的NO和TNF-α响应，也在不同流程中测了感染细胞内细菌的利福平存活。腹腔细胞经硫乙醇酸诱导募集后收集，因此仅凭群体平均细胞因子读数，不能判断变化是每个细胞内在重编程、被测亚群比例变化，还是两者兼有。论文另有体外训练及骨髓来源巨噬细胞结果，为细胞内在训练提供支持，但仍没有用群体平均测量证明每个细胞的变化。

谨慎表述应是：**在该细胞来源和实验流程下，收集到的细胞群体平均再刺激响应发生变化。** 这比声称“每个细胞都改变了内在状态”更符合现有测量。

## 问题变化与分歧

问题由“状态、组成和细菌耐受各贡献多少”缩窄为：对于明确的后续挑战和目标功能读数，最低限度需要怎样描述刺激历史、被测细胞身份与群体组成，才能判断响应是否可预测？分歧在于物理视角强调对目标响应的预测充分性，免疫学视角强调细胞来源、诱导募集和亚群构成是界定状态的生物条件。现有数据没有区分单细胞内在重编程和群体组成变化；这表示证据不足以裁决，而非两者贡献已知相等。

## 交流产生的补学请求

需要了解硫乙醇酸诱导腹腔巨噬细胞的群体异质性，以及哪些测量能够区分训练后细胞内在响应变化与亚群组成/存活差异。这个缺口现在变得重要，是因为共同问题已明确以“被测群体”为状态描述的一部分。
