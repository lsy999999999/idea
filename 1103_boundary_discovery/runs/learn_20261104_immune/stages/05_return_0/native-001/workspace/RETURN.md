# 返回共同讨论

## 共同对象

**组成条件下的指定挑战群体响应。** 细胞来源、取样/培养流程和挑战共同界定被测群体；群体读数可用于预测目标功能，但不自动识别其微观来源。预测群体响应和解释响应来自细胞内状态、有效组成权重、存活还是细胞间作用，是两个相关但不同的问题。金黄色葡萄球菌研究中的LPS炎症读数与胞内细菌存活读数仍分属不同实验支路。

## 混合例子何时适用

物理侧的算例在以下近似条件下很有用：各细胞贡献近似可加、检测保持线性、亚群权重确实对应对总体信号的有效贡献，并且旁分泌/接触作用与差异存活可忽略或另行处理。这能说明“单一均值无法唯一确定微观分布”，但不证明真实培养过程符合该模型。

综述给出的腹腔背景说明这种担忧有生物学相关性：LPM和SPM具有不同来源与功能倾向；炎症条件下二者以及炎性单核细胞在腹腔中的代表性会改变。综述还描述过细胞群构成与LPS后NO响应共同变化的情况。那只能作为组成效应可能相关的实例，不能说组成变化单独造成了响应差异，更不能推断目标金黄色葡萄球菌研究已发生同样的组成变化。

## 保留的问题分支

1. **群体预测：** 给定明确训练、采样/培养和LPS挑战，哪些群体级信息能够预测预先指定的NO/TNF-α终点？
2. **微观可识别性：** 同一群体均值变化何时能区分亚群内响应、有效组成权重、贴壁/存活选择和细胞间作用？现有目标数据还缺什么信息？
3. **宿主-病原联系：** 若关注宿主历史与细菌药物存活，如何配对测量而不把炎症支路和胞内细菌存活支路合成一个读数？

这些分支都仍未完成。当前综述提供的是小鼠腹腔一般知识；目标实验的细胞亚群、有效权重及读数归一化仍未知。
