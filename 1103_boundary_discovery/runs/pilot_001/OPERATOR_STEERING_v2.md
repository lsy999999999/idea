# 探索优先：在已取得证据后检验新解释

本轮用户目标是能产生新 idea 的研究系统。现已取得真实观察、原三站独立复算、新站数据和两个明确的高频波形候选。下一项正在执行的新站复核可以完成，但不要继续用剩余预算串行重复全面覆盖/格式/统计审计。

完成当前新站复核后，请优先读取 `contributions/005_parallel_theory_completed.json` 及其正式理论提案，把剩余研究动作花在一项能区分解释的实际计算上。可选择相位/夜间不对称、河网波形关系，或有证据支持的更好问题；可以推翻这些候选。不指定正确公式或预期结论。

请让理论提案变成具体的、足够小的预测检验，而不只把“空气温差改善回归预测”作为最终成果。优先复用现有原始高频数据，先冻结变量和预测，再选择未参与该波形探索的年份。若河网核实、机制识别或新的气象测量暂不可得，应先完成当前数据能够回答的区分，并明确留下的问题。

在探索阶段，完整探头历史、所有潜在混杂、全面文献综述都不应成为开始计算的前置审批。具体错误要修复；未知条件限制解释范围。独立复算已经为主要数值提供了检查，剩余计算主要用于产生新认识。若新解释失败，就保留失败并说清从中学到了什么。

原有数据和已完成结果保持不变。本文件是对执行优先级的公开调整，不增加科学结论，也不把已知概念视为原创。阶段仍须保存代码、实际输出、使用范围和有信息量的下一步。
