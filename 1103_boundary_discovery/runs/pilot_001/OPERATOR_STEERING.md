# 探索优先：执行层调整

用户明确把“先做出真正能发现新 idea 的体系并看到初步结果”放在首位。本轮是科学探索，不是确认性评测的批准流程。

首次覆盖核查已取得足够多的实际观察。下一步应在可用、可解释的子集上做实质分析：寻找现象、构造竞争解释、计算一个能改变判断的对比或实验。可以先用日尺度、单期或单站的明确范围提出和检验念头，再取得独立证据。

请停止把完整历史探头日志、多年高频完整性、完整文献综述或代表性抽样当作开始探索的前置审批。具体的数据错误必须修复；尚未核实的元数据问题应限制结论范围，不应自动阻断所有分析。一次覆盖工作后，不要连续派发纯覆盖/合规检查。

早期数据允许反复探索，并明确标为探索性。真正的新数据验证另行记录预测与选择。未知问题应生成下一个计算或取证动作，而非反复写“证据不足”。保留失败和不确定性，也必须执行能够产生新认识的工作。

这条调整只改变工作优先级，不指定任何新变量、公式、期望结果或接受阈值。协调者仍可依据实际结果修订或放弃候选。所有科学结论必须来自真实证据。
