Access level: full text of the UCI dataset documentation was retrieved previously in the supplied source file winequality.names; this file preserves the relevant excerpt for this learning stage.

The output is based on sensory data (median of at least 3 evaluations made by wine experts). Each expert graded the wine quality between 0 (very bad) and 10 (very excellent).

Due to privacy and logistic issues, only physicochemical (inputs) and sensory (the output) variables are available (e.g. there is no data about grape types, wine brand, wine selling price, etc.).

The datasets can be viewed as classification or regression tasks. The classes are ordered and not balanced. Several attributes may be correlated.
