# 返回共同讨论：目标先于评分指标

## 共同对象与问题

共享对象仍是理化测量与专家面板评分的关系，但现有 UCI 表中的 quality 是至少三位专家评分的中位数。它只直接支持对该特定聚合输出作描述或预测，不能从中位数恢复个体评分分布、评分者差异或潜在感官属性。

我的学习把观测设计具体化为评委与酒样相链接的交叉评分：来源中的全交叉心理测量例子按对象、评分者、案例分解方差来源；同伴学习则补充绝对值一致与相对排序一致并非同一目标。因而问题应先确定应用上关心的是绝对评分可互换、样本排序稳定，还是评分者间差异来源，再决定所需设计和测量指标。

## 为什么改变

起初我只问理化指标的关联在个体评分和聚合分之间是否稳定。外科评估来源 K6a6a58450c07c23e 说明 fully crossed person-by-rater-by-case 数据可用于估计多种方差成分；K118ec9a5b92de666 的试点说明只有一位专家评分时无法估计评委间可靠性。它们不是葡萄酒研究，只提供一般设计启发。同伴读到的 Hallgren 教程进一步明确：absolute agreement 关心绝对评分是否接近，consistency 关心相对排序；IRR 与 construct validity 也不同。这个补学使我把“评委共识”拆为可替换的不同目标，而不是一个含糊结果。

我们仍未决定这次最值得问的科学问题，也未确定三位以上有序评委的适用统计量。没有 UCI 个体评分、评委ID或交叉结构，不能对这些量作当前数据估计。

## 保留的问题分支

1. **给定流程的聚合分预测：**理化指标能否预测现有中位数？这是最贴近当前数据的预测目标，但不能等同于感官机制解释或评委可靠性。
2. **评委间绝对评分一致：**不同评委是否会给同一酒样相近的绝对分？需有个体分及与评委/样本链接；当前数据不能估计。
3. **评委间相对排序一致及方差来源：**评委对酒样高低顺序是否相近，评分者严厉度、酒样和交互各占多少变化？这可能需要全交叉和重复设计；是否对筛选应用有意义尚未知。
4. **潜在感官属性或构念效度：**聚合评分是否代表一个独立于评审流程的感官属性？可靠/一致的评委评分并不自动证明效度，需另外定义构念与外部证据。此分支没有被前述统计学习解决。

前三个分支不互相替代，第四个也不能从高一致性推出。没有放弃任何分支；只是将“理化—评分关联稳定性”降为需先定义目标后的后续问题。

## 来源边界

- UCI Wine Quality 数据文档：https://archive.ics.uci.edu/dataset/186/wine+quality；现有表的评分定义和字段范围。
- Hallgren (2012), *Computing Inter-Rater Reliability for Observational Data: An Overview and Tutorial*：https://doi.org/10.20982/tqmp.08.1.p023。给定全文摘录在 `/Applications/ideas/1103_boundary_discovery/runs/e2e_eval_20261106_wine/stages/04_learn_1/native-001/workspace/source_hallgren_2012.txt`。文中指出 fully crossed 设计允许评估并控制 coder 系统偏差；也区分 IRR 与 validity。该教程为行为观察方法，不是葡萄酒感官专论。
- 两篇外科评分文章只作为非领域设计例子：K6a6a58450c07c23e (`https://doi.org/10.7759/cureus.113882`) 与 K118ec9a5b92de666 (`https://doi.org/10.7759/cureus.117189`)；快照路径在我 04_learn_0 结果的 evidence 中。不得将其具体效果外推到酒评面板。

下一步若继续，应只针对“至少三位、有序评分、交叉/不完全交叉”寻找具体方法依据，并询问拟议应用究竟需要 absolute agreement、排序 consistency，还是对潜在感官属性的效度证据。无需现在选择最终 idea。
