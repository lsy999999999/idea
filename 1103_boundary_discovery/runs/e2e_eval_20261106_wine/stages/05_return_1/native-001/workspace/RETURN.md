# 返回共同讨论：先定用途，再定评分目标

## 共同对象

UCI Wine Quality 的 11 项理化测量与专家评分关系。`quality` 是至少三位专家评分的中位数，是特定评审流程输出；它不是个体评分、评委可靠性或已证明的潜在感官真值。

## 问题怎样变化

我的起点问：若获得逐位评分及样本/批次来源，理化指标关联中哪些在评委层稳定、哪些只预测面板聚合分？

同伴先指出应先选择 estimand。我之后学到 absolute agreement 与 rank consistency 的差别；同伴的学习则补充完全交叉评委—样本结构可用于评估系统评委偏差和多个方差来源。可靠/一致评分仍不能替代构念效度。

问题因此改为：**在实际用途下，目标是预测既定流程的中位数、要求评委绝对评分可互换、保持酒样排序/分析差异来源，还是验证独立潜在感官构念？每个目标需要什么评分链接、交叉/重复设计和外部证据？理化测量的关联是否会随目标改变？**

## 保留的分支

1. **聚合中位数预测。** 可用当前表格研究对既定流程分数的描述或预测，但不说明评委可靠性或感官机制。UCI 对原研究结果有转述；它不是本轮新发现。
2. **绝对面板一致。** 若用途需要不同评委给出相近绝对分数，需要逐位评分以及酒样、评委链接；当前中位数不能估计。
3. **相对排序与方差来源。** 若用途只需样本排序，或希望分解评委严厉度、样本与评委×样本差异，设计需保留共同对象的评委链接；具体重复/交叉结构和三评委以上的有序统计量仍未决定。
4. **潜在感官构念效度。** 需要独立定义构念和外部效度证据。可靠性/一致性再高也不能单独证明量表有效。

当前没有人要求将这些分支压成一个最终问题；也没有实质分歧。先前“逐位评分与聚合分的关系是否稳定”仍可作为第 1 与第 2/3 分支之间的后续桥接问题，需待实际目标确定。

## 仍未决

Hallgren 教程说明了 ICC 的绝对一致和排序一致形式、完全交叉设计及两评委加权 Kappa，但没有为 UCI 的三位以上序数评委确定适用系数。当前表格没有逐位评分或评委ID；潜在感官属性还需要独立效度证据。下一步可以继续询问实际用途，或定向补足多评委序数方法，但本轮不预设哪条支路优先。
