# 共同讨论中的问题分支

本记录整理两位研究者的原始提问、交流后的变动和返回讨论中明确保留的分支。没有选择唯一方向；讨论并未放弃任何分支，也没有完成新颖性或可行性筛选。

## 起点：关联稳定性

研究者 0 最初问，理化指标与聚合 `quality` 的关联中，哪些在个体评委层面稳定，哪些只预测面板聚合分数；这需要逐位评分及样本/批次来源。交流后，这一问被放回更基础的目标定义之前：如果目标是既定流程的中位数预测，可以直接研究表内分数；如果目标是评委效应、排序或感官构念，则估计对象和观测设计都要改变。它没有被否定，仍可作为聚合分支与个体评分分支间的后续连接问题。

## 明确保留的四个分支

1. **给定流程的聚合中位数预测。** 研究理化测量与现有中位数分数之间的关系。它贴近当前表的观测目标，但讨论明确说这不等于评委可靠性或感官机制解释。已有 UCI 文档转述的预测研究是已发表背景。
2. **绝对面板一致。** 问不同评委是否会对同一酒样给出相近的绝对分数。需逐位分数及评委、酒样链接；当前中位数不能估计此目标。
3. **相对排序一致与方差来源。** 问评委对酒样的相对排序是否稳定，或评分者严厉度、酒样差异、评委×酒样差异如何区分。研究者提出交叉与重复记录作为可能需要的设计，但没有选定有序多评委统计量。
4. **潜在感官构念效度。** 问评审流程的评分是否代表一个事先定义、独立于流程的感官属性。学习中特别区分了可靠性/一致性与效度；需另行定义构念并有外部效度证据，当前表及讨论未提供这些证据。

## 仍未解决

“最值得研究的问题”没有由参与者决定。最初的“个体与聚合关联是否稳定”依赖于先确定实际用途和目标量，不能替代以上四个问题。两人都指出现有 UCI 表只有多位专家评分的中位数，没有个体分、评委 ID 或交叉/重复结构；本轮没有据此估计分歧、可靠性或潜在属性。
