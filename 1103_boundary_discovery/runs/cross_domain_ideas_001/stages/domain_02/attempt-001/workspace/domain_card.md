# Domain Card: Immunology and immune memory

## Structures

1. **Memory as a differentiated family of states.** An infection gives rise to multiple effector and memory CD8 T-cell types whose phenotype, function, location, and long-term contribution to the memory pool vary. The object of explanation is therefore a distribution of cell states and fates, not one binary effector-to-memory switch.
   - Assumptions: State categories are useful summaries of heterogeneous cells; measured phenotype and location do not necessarily determine future fate.
   - Source: Kaech & Cui (2012), https://pubmed.ncbi.nlm.nih.gov/23080391/ (accessed 2026-11-04). Review abstract describes multiple types and variation across phenotype, function, location, and long-term fate.

2. **Memory as persistent history-dependent response capacity.** Innate cells can retain a changed response propensity after an earlier exposure through sustained epigenetic and physiological reprogramming, without permanent genetic change or adaptive receptor rearrangement. Thus memory can reside in altered response rules rather than only in a clone that recognizes the same antigen.
   - Assumptions: The altered state persists long enough to affect a later challenge; “memory” is being used functionally and does not imply the same specificity mechanism as B/T-cell memory.
   - Source: Netea et al. (2016), https://pubmed.ncbi.nlm.nih.gov/27102489/ (accessed 2026-11-04). Review abstract identifies trained immunity and sustained epigenetic changes in gene expression and cell physiology.

3. **Memory as spatially situated but plastic.** Tissue-resident memory can provide rapid local responses, while its members vary in phenotype and function and can exhibit longevity, plasticity, and retrograde migration. Location is part of memory organization, but need not be an immutable boundary.
   - Assumptions: Local tissue position changes which threats a cell can encounter and how quickly it can respond; “resident” describes a tendency or state, not necessarily irreversible confinement.
   - Source: Strobl & Haniffa (2023), https://pubmed.ncbi.nlm.nih.gov/37144705/ (accessed 2026-11-04). Review abstract covers heterogeneity, formation, longevity, plasticity, migration, homeostasis, and disease.

## Open tensions

- How should “specificity” be represented when later protection can be clone/antigen-linked, cross-reactive, or a broad trained response? What evidence distinguishes recognition of a recurrent threat from a generally shifted response threshold?
- How can persistence be reconciled with plasticity and migration: does durable memory require stable cell identity, or can it be maintained as a changing population or a distributed physiological state?
- The same memory architecture can support rapid protection and contribute to allergy, autoimmunity, inflammation, or malignancy. Which features make local readiness protective in one context and damaging in another, and at what spatial or temporal scale should that tradeoff be described?
