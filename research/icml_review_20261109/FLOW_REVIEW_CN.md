# 当前科研流程审查与修正 · 2026-11-09

以 ICML 方法论文的标准看，当前最需要补强的是：能否准确区分研究者的猜想、审阅者的质疑和已经核实的错误；能否追踪修正对后续推理的影响；实验能否支持所声称的机制优势。代码和执行记录确实暴露了可修复的问题，下面的修改已落实。

保留完整上下文进行续研是合理的默认设计。当前假说、前序推理和长期记忆都可以进入新的模型调用。原先不准确的是把这种调用描述成“只读记忆”，并可能据此归因长期记忆的独立作用。按用户澄清，默认保持 **full_context**；只有显式选择 **memory_only_probe** 才进行第一轮输入消融。后一模式不默认运行，也不代表完整科研系统应该丢弃上下文。

| 发现 | 对结论的影响 | 修正 |
|---|---|---|
| 审阅意见被直接赋予 needs_correction 状态 | 有真实引文不代表反驳成立，条件性假说可能被错误意见带偏 | 保留 reviewer_status，控制器报告先记 undetermined，并标明只核验了引文或计算表达式；作者可接受、反驳或保留未决 |
| 算式重算被混同于来源判断 | 审阅者可以选错数字、坐标或表达式，即使计算执行正确 | 明确 recomputed_expression_only；不将模型自填算式的差异升级为已验证的原文错误 |
| 接受纠正却只更改 kind/revision_reason | 记忆看起来纠正了，原错误内容仍原封不动 | 接受纠正时检查 understanding/conditions/example/open_questions 至少有实际内容变化；反驳可保留原内容并记录理由。该检查排除空修改，不自动判定改写正确 |
| 只有 influenced_by，没有显式前提依赖 | 上游前提改了，下游分支可能继续使用旧版本 | 增加 depends_on、直接及传递的 revision_obligations、dependency_responses；研究者可修订、重新确认、搁置或未决。影响来源不自动视为逻辑依赖 |
| 只修改依赖引用也可能被计作内容进展 | 版本维护可能冒充新理解 | 将引用更新与实际内容字段变化分开，停滞检查不把仅依赖维护算作内容进展；字段变化仍不等于科学质量提升 |
| 无效记忆可能在问题/假说已提交后才失败 | 一次失败留下部分科研状态 | 主流程提交前先校验记忆；原生交接补充问题、假说、服务请求和反馈回应校验 |
| 审阅材料截断于 100,000 字符却保留全文哈希 | 末尾证据不可见且完整性验证不一致 | 原文不截断；API 用内容引用与分页控制输入量 |
| 完整上下文续研被称为“仅靠记忆” | 错误归因长期记忆效果 | 默认保持完整上下文并记录 CONTINUATION_SCOPE；增加可选 memory_only_probe，API 下关闭 CSV/外部检索；核验所声称使用的记忆 key/version/source_task |
| comparison_config 的公平性目标写成已达成事实 | 机器读取配置可能误报等数据、等资源比较 | 分开 fairness_targets 与 observed_fairness；记录实际访问不一致、资源不匹配、硬件限制未统一执行；新复跑目录不继承旧运行完成状态 |

显式依赖只覆盖模型实际声明的前提，不会自动发现漏报的语义依赖，也不完整覆盖跨运行记忆与全部证据的关系。复核提醒不删除假说，不强迫接受批评，不以缺少数据、证明、实现或可行性为淘汰条件。最终 ideas.json 保留未决依赖提醒。

真实光学内审意见的复核：旧意见以完整 spread 数据中 S3 最小值约 0.73945，质疑“若相位展宽使空间贡献相消，DOP 可下降而 S3 仍近似稳定”。这可能提示限定适用范围，但单凭最小值不能推翻带“若”的条件命题。新流程保留这条质疑，标作待判断，不自动宣布它已证明原假说错误。旧内审报告未被覆盖。

验证共 **167 项**：主流程 62 项、历史流程 80 项、API 25 项。主流程测试覆盖材料→独立初读→交流→补学→内审→作者回应→续研→候选保留→冻结→终审，以及中断恢复。恢复时复用已提交的笔记，不拿未来记忆版本反过来要求历史初始笔记提供修订理由。新增对抗检查包括错误批评、接受但不改内容、跨分支传递依赖、虚构记忆版本、长材料末尾证据、无效记忆提前拦截。研究角色在这些测试中使用可控样例；这证明控制器行为符合约束，不证明真实模型的科学推理水平。

如果投稿主张“纠错机制提高新假说质量”，目前证据仍不足，不能靠改代码补成结果。还需要在相同信息、工具、模型和实际资源条件下，加入有理批评与错误批评的配对案例，比较完整流程、去除依赖复核、去除记忆及简单流程；报告错误接受、正确观点误改、旧前提残留，以及新问题是否带来实质假设/关系变化。评价者须区分结构合法、科学正确、研究价值和新颖性。近年的 Nature/Science 材料也不能直接保证预训练未见或世界新颖性。

本轮使用源码审查、旧运行复核及可控回归，新增付费模型调用为 0。核心修复写回当前工作树，API 修复写回可复用适配层；使用 learning-inquiry-v4 / tool-transport-v4 开新运行，旧运行继续使用其归档源码。原先已有的未提交修改和封存实验均保留。
