# 情境 A：扰动后的微生物群落

从公开的微生物群落扰动与恢复研究开始，关心可实际观察到的群落组成、功能、时间变化及其测量方式。引入非平衡物理研究者共同理解材料。最终问题保持开放，可以改变对象、尺度和问题。

材料整理者自行选择一项能读到研究内容的具体原始研究，并补充必要综述或基础理论。分别记录观察、观察条件、期待、期待依据和已有解释；如果没有明确期待就写未知。保存公开来源正文或可用摘录，逐项标明所读范围，不能把文献结论写成新实验数据。不要预先指定共同假说，不使用项目历史候选。

首批研究者：microbial_ecologist（群落生态、扰动和功能）；nonequilibrium_physicist（动力学、状态、记忆和观测）。由资料决定实际补学内容。
