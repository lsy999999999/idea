# 情境 B：免疫系统的重复暴露与记忆

从公开的免疫系统初次与重复刺激研究开始，关注刺激条件、细胞状态、群体组成、功能响应及其测量方式。由免疫学研究者与已有的非平衡物理研究者共同探索。最终问题保持开放；不能因为上一任务讨论过某种机制就认定本情境也适用。

材料整理者自行选择一项可读取内容的具体原始研究，并补充必要综述或基础理论。区分观察、期待及其依据、已有解释和未知项；保存来源正文或可用摘录。初始材料不加入前一任务的候选。物理研究者通过有出处的长期笔记取回相关积累，并主动检查类比边界。

首批研究者：immunologist（免疫记忆、细胞状态和群体响应）；nonequilibrium_physicist（沿用同一身份和知识库）。可以继续扩展知识范围。
