# 葡萄酒理化性质与感官评分：开放共同探究

从 UCI Wine Quality 数据集出发，探索哪些观察、解释或测量问题值得形成研究 idea。
数据入口：https://archive.ics.uci.edu/dataset/186/wine+quality
原始表：https://archive.ics.uci.edu/static/public/186/wine+quality.zip
红酒 1,599 行，白酒 4,898 行，11 项理化指标与整数感官评分。
实际下载并核对字段、数量、缺失和测量说明；区分数据直接支持的描述与需要新观测的问题。
来源论文可以阅读，属于已公开背景；本次为当前知识条件下的 idea 生成，不声称历史盲重发现。
两位研究者独立理解材料、共同提问、按需补学、返回讨论，保留实际形成的想法。
优先新研究问题和概念内容，不要求现在解决、证明或完成实验。
研究者只能读取调度时列出的输入、来源和本次提供的记忆，不得读取历史候选或本次评价材料。
