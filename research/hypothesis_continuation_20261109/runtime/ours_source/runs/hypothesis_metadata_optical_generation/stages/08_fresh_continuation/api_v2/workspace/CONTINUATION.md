# 延续：方向归一化与合成信息

## 使用的记忆

- 键：`stokes_average_before_normalization`，版本 1，来源任务 `hypothesis_metadata_optical_generation`。
- 用途：调用“先平均再归一化”与“先丢弃幅度、仅保留方向”保留信息不同这一关系，构造两方向向量的学习示例。
- 适用范围：一般向量聚合的条件关系；不说明本案的S1/S2/S3处理链，也不确定DOP的物理含义。

## 小例子

取两个等权方向 `s1=(1,0,0)`、`s2=(-1,0,0)`。先平均得到 `(s1+s2)/2=(0,0,0)`，模长为0。零向量没有可归一化的方向。若输入在聚合前被压缩成单位方向且幅度或权重被丢弃，之后的方向记录不能一般地唯一确定加权合成模长；若实际流程是先聚合再归一化，则不是同一信息丢失情形。

这是抽象学习计算，不是本案测量数据拟合或验证。案例实际平均、强度权重、归一化次序及DOP估计来源仍未知。
