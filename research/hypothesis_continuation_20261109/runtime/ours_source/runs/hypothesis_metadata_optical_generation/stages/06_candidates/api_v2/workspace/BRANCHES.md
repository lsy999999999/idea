# 分支记录

以下当前分支均保留；状态不表示成立。

## `unit_direction_vs_dop`（theory_scientist v2）
假设S1/S2/S3方向字段与DOP是不同估计对象；近单位范数有助于提出此工作区分，但不足以确认逐行归一化操作或估计链。条件后果：若逐态单位化先于聚合且尺度/权重丢弃，方向不足以确定后续加权合成的模长；若DOP独立估计，不等于丢失的长度。保留为I1核心条件框架，不当作案例事实。

## `unit_direction_vs_dop`（domain_scientist v1）
较宽的字段分离分支，包含低偏振条件下方向统计可能受测量不确定度影响的可能性。此点仅来自摘要层级的背景且适用条件未知；未并入确定结论，作为I1的测量不确定性子问题保留。

## `conditional_preaggregation_unitization`
若聚合前逐态单位化并丢弃长度/强度权重，方向不能一般地重建后续加权合成的长度或抵消程度。保留为条件分支；未证明本案如此。

## `postaggregation_normalization`
若先进行加权Stokes合成再归一化，方向表示合成结果方向，逐态先单位化的信息损失推论不适用；方向本身仍不携带长度。保留为与前一分支不同的处理链。

## `independent_estimation`
若方向与DOP来自独立估计链，DOP变化可与近单位方向列并存，而不必解释为方向丢失了模长。保留；估计器定义缺失。

## `phase_spread_cancellation`
若dphi确实表示相位分布展宽且其他条件、定义固定，相位平均导致偏振分量抵消是候选解释。保留为未决物理支线；扫描趋势不作因果证据。

## 讨论与学习中的未转化支线
- 方向分量的均值相对相位变化如何对应偏振态方向旋转，取决于基底、相位参考及处理定义；保持开放，不另造确定机制。
- 不同光学系统可把不同偏振性质编码在不同信号特征；PS-OCT摘要只是类比，未证明适用于本案。
- 仪器响应、校准、样品/扫描条件、拟合或导出尺度都可能解释spread扫描DOP趋势；均未判定。
- 两扫描DOP刻度分别约0–100与0–1，且不是独立重复；不合并、不由其差异形成跨扫描解释。
