# 候选 Ideas

## I1：偏振方向字段与DOP的处理链

**Idea：** 研究在光学偏振扫描中，强度加权Stokes合成、跨状态平均、方向归一化及DOP估计的不同次序，如何决定S1/S2/S3方向字段和标量DOP各自保留的信息。条件性地，若逐态方向先单位化且幅度/权重被丢弃，仅有方向一般不能确定后续加权合成的模长或抵消程度；若先合成后归一化，该特定信息损失推论不适用；若DOP来自独立估计链，也不自动等于丢失的模长。当前扫描中S范数全行近1，但这不识别其生成算法。研究问题是确定这些映射关系及其适用条件，不声称本案处理流程已知。

**动机：** brief明确提醒S分量范数不可假定等于DOP，并称两条扫描DOP刻度不同。两扫描全CSV的S范数均接近1；方向与标量DOP因此值得分别追踪。研究者的问题从“改变了哪些场量、如何映射字段”及“是否同一对象/归一化步骤”，经交流转向平均、加权合成和归一化次序对信息保留的影响。

**涌现路径：** `stages/02_initial_0`提出场/偏振量到输出字段的映射问题；`stages/02_initial_1`引入方向与DOP是否同对象的疑问；`stages/03_exchange_0`提出测量/平均/归一化管线；`stages/03_exchange_1`具体化处理次序；`stages/04_targeted_0_learn_1`将其细化为强度加权合成与信息损失；`stages/05_return_1`保留条件性推论且强调算法未知；`stages/06_candidates`以两相反等权向量作学习示例，未识别案例流程。

**领域：** 光学、偏振测量、Stokes/Mueller表征、测量与信号处理。

## I2：相位分布展宽与偏振抵消的条件关系

**Idea：** 在明确的相位分布及固定其他光学条件、测量定义的前提下，研究相位分布展宽何时会造成合成偏振分量抵消并降低偏振度。现有spread扫描DOP随dphi增加下降只是单次导出扫描的线索，不证明dphi的物理含义或该机制。该问题与I1的字段处理链有关但不等同：即使字段映射明确，物理相位分布到合成偏振的关系仍需界定。

**动机：** 材料预期在“dphi确为相对相位分布展宽且其他条件固定”时，相位平均可能降低合成相干分量；研究者一直保留仪器、后处理、尺度和扫描条件等替代分支。它从最初对控制相位所改变的光学量的追问中出现，后续始终作为条件候选而未被确认。

**涌现路径：** `stages/01_materials_recovery`分别整理spread与mean-phase扫描及条件性预期；`stages/02_initial_0`询问控制量改变哪些场/偏振量；`stages/03_exchange_0`至`stages/05_return_1`保留相位抵消为一种可能而拒绝据输出趋势归因；`stages/06_candidates`仍将其列为未决条件分支。

**领域：** 光学、偏振、相位统计、相干与测量。

**状态说明：** I1是交流聚焦的主问题；I2是独立保留的物理机制问题。未预筛新颖性、证据强弱或可行性。
