# 共同讨论回归

## 改变依据
两位研究者的学习没有确定本案字段生成算法，但把原先宽泛的“方向与DOP是否对应”收窄为可区分的表示问题：逐态单位化后丢弃长度/权重，与加权合成后再归一化，保留的信息不同。接受同伴的关键限定：范数近1是数据特征，并不能识别具体运算。摘要级偏振背景可支持Stokes参数与Poincare球的一般联系，却没有提供案例流程定义。

## 共同对象
两条独立扫描中，底层偏振信号经测量、加权合成、平均、估计与归一化后，映射成S1/S2/S3方向字段和DOP的过程。spread扫描预览显示DOP由约93降至31，而方向范数仍接近1；这只是导出字段共现，不足以辨明机制或运算顺序。两条扫描不作为重复试验合并，且各自DOP刻度不可混用。

## 共同问题
在两条偏振扫描中，哪些测量与处理步骤分别生成S1/S2/S3方向字段和DOP？特别是强度加权Stokes合成、跨状态平均与方向归一化的次序，如何决定尺度或权重信息是否保留？

## 分支
- 若逐态先单位化且丢弃长度/强度权重，方向集合一般不足以唯一决定后续加权合成的模长或抵消程度；本案是否如此未知。
- 若先合成再归一化，方向代表合成结果的取向；逐态丢尺度导致不可恢复的推论不适用，但方向本身仍不编码长度。
- 若S字段与DOP来自独立估计链，两者可以共存而不构成同一向量的方向—长度分解。
- 若dphi确是相位分布展宽，且其他条件与DOP定义固定，Stokes分量抵消是降低DOP的一种候选解释；不据目前资料归因。
- 测量不确定度可能影响低偏振条件下方向统计的解释；本案是否处于相应条件未知。

## 保留的问题与放弃的推断
保留：本案S分量的归一化对象、DOP计算方法、强度权重及平均顺序均未定义。放弃把近单位范数当作逐行单位化算法的证明，也不把DOP下降认定为相位抵消机制。不同扫描不池化；spread与mean-phase的DOP刻度不直接合并。
