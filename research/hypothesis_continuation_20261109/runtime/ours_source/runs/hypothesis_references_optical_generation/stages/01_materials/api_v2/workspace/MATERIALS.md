# 光学偏振扫描：开放材料

## 范围与阅读方式

案例输入包含两组不同 source scan：spread 控制与 mean-phase 控制。它们不是独立重复制备，且 DOP 导出尺度不同；因此分开描述，不把原始DOP值跨扫描比较。当前仅有brief统计与预览，不据此构造完整曲线或误差估计。

## 材料一：相位分布展宽扫描

- **观察**：102点，`dphi`约0至0.505。brief预览的代表点显示DOP从约93.14降至约31.00；统计全范围约0至0.505、平均0.2525。该趋势需用完整CSV及单位核验。
- **条件**：brief称其为phase-distribution spread控制；dphi单位未核实。此扫描DOP约0–100刻度。
- **条件性期待**：若dphi确实代表相对相位分布展宽，且其余光路、输入幅度、测量和导出定义固定，随机相位平均会削弱相干叠加，故可预期偏振度下降。这里是理论模型下的期待，不是对原论文预期的断言。
- **已有解释/歧义**：相位平均引发抵消是一个可能机制；仪器响应、归一化、DOP定义或伴随变化也可能影响趋势。来源未给足条件来区分。

## 材料二：平均相位扫描

- **观察**：另一组200点，mean_phase从0到2π。预览显示S1/S2/S3方向分量随相位改变；DOP导出值在约0.70–0.84量级。不得与前一扫描的约0–100刻度混用。
- **条件**：mean_phase为相位控制；S1/S2/S3是导出的归一化方向分量，brief特别提醒不要假设其平方范数等于导出DOP。
- **条件性期待**：若只改变相对相位且振幅、基底与仪器固定，理想偏振方向可随相位周期变化；理想完全偏振状态的归一化Stokes向量范数为1。实际DOP与向量范数之间是否应相等，取决于数据字段定义和处理流程。
- **已有解释/歧义**：相位控制可改变偏振椭圆方向/形状；DOP与方向分量不一致可能来自不同定义、平均操作或噪声，但目前没有依据选定解释。

## 独立领域背景

K1为2020综述的索引摘要，不是全文。它指出经典光的偏振由Stokes参数描述，并可用Poincare球几何解释；同时提醒量子情形的偏振度定义更复杂。该综述提供概念背景，不证明本案例的特定相位机制。

## 读到的来源
