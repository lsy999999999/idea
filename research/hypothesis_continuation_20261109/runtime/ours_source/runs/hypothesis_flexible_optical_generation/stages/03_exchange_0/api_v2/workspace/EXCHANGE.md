# 偏振方向字段与 DOP：测量表示链

## 共同对象

暂不把导出的 S1/S2/S3 列直接等同于某个物理 Stokes 向量的方向，也不把 DOP 直接等同于该向量的长度。共同对象改为“光学信号到报表字段的测量表示链”：在每个控制条件下，信号经测量、平均、归一化或拟合，生成方向字段与 DOP 标量。这里的阶段和映射仍待原始定义确认。

## 对同伴问题的回应

对方提出：两扫描中 S1/S2/S3 的几何方向与 DOP 是否描述同一对象、同一归一化步骤，尤其 spread 扫描里 DOP 随 dphi 下降时，究竟是物理偏振度变化，还是单位化方向之外另行处理的标量。

我同意先将两类导出量分开理解，但收窄一个推断：全行范数近 1 是数据列的数值性质，不单独证明其由逐行单位化操作造成。若单位化成立，方向字段会丢失长度信息；DOP可能补充另一类信息，但未必是同一未归一化 Stokes 向量的长度，除非定义和处理次序确立这一关系。

概念上，关键不只是“范数是否等于 DOP”，而是两字段分别对应估计管线的哪一步。若相位样本先以强度加权合成、之后再提取方向，和先对各态单位化再平均，所得方向及长度一般可能不同；这是对处理顺序的条件性推论，不是本案已知流程。

## 有限连接与边界

《Quantum concepts in optical polarization》摘要将经典偏振与 Stokes 参数及 Poincare 球联系起来，支持把方向作为几何信息来思考，但不提供本案字段的算法。PS-OCT 摘要报告 retardation 由两通道振幅比编码、轴向由相位差编码；这只是“不同偏振性质可由不同信号特征表示”的迁移类比，不能证明当前装置使用相同方法。

因此，条件性地，若 S 列是逐行归一化方向，而 DOP来自归一化前的加权合成，DOP可承载方向字段已丢失的长度信息；若 DOP 来自另一估计器、另一平均层级或不同刻度，则不能这样解释。案例 brief 明确说两次扫描不可作为独立重复，且 DOP 刻度不同，故分别保留，不跨扫描作原始数值比较。

## 保留的分歧和问题

分歧只在推断强度：同伴认为范数近 1 支持单位化解释；我认为它支持保留该解释，但不识别具体生成操作。共同问题是：S1/S2/S3方向列与导出 DOP 分别对应测量、平均和归一化管线中的哪些估计对象或步骤？spread 扫描的 DOP 下降中，哪些结论来自字段定义，哪些依赖尚未确认的处理顺序？
