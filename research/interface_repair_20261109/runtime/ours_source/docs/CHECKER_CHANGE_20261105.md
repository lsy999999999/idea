## 对提案的六点调整

1. **并列报告方向与贡献。** 非常相近的方向可同时有未被覆盖的实质主张；`already_done` 是方向判断，逐主张比较说明贡献范围，不能据方向标签直接丢弃全部内容。
2. **按候选主张决定重要维度。** 放宽假设或新验证机制可能就是贡献本身，不能总把 assumptions/validation 放在次要地位。六维不作固定加权。
3. **区分关系和证据状态。** 覆盖关系用六个标签，证据另记全文／摘要／元数据／不可访问。摘要缺细节是未知，不是差异；摘要有明确覆盖陈述时也不必一律等待全文。
4. **忠实拆解原始问题。** 每条提取主张绑定原文；一个待研究问题即可成为比较对象，不强制补齐方法或成功结论。程序核对原文片段存在，语义忠实性仍由模型判断。
5. **单独比较有意义的组合。** 若候选真正声称组合产生新机制／能力，保留组合主张，逐项核查；多篇分别覆盖模块不自动覆盖整合主张。整体 `COVERED` 要求同一来源覆盖全部核心主张，多来源分散覆盖列为 `PARTIAL_OVERLAP` 交回分析。
6. **先返回差异与下一步。** 证据不足引导补检，有依据的覆盖可引导修改建议。修改保留原始科学目标，并解释差异为何重要。自动生成—修改—复查循环留作后续，不在本次启动。
