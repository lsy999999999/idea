我有一个比较明确的想法，而且我觉得它比“让 LLM 不断猜测缺少什么变量”更值得研究。

不要让 Agent 一开始就寻找未知的 \\(Y\\)。应该先让它从原有公式的失败中，推导出：这个未知的 \\(Y\\) 必须具备什么性质。

这是一个很重要的思路转变。

假设人类目前用：

\\[ O=f(X;\\theta) \\]

解释某个现象，但真实关系可能是：

\\[ O=g(X,Y;\\phi) \\]

我们不知道 \\(Y\\) 是什么，甚至不知道它是否存在。

传统思路是让 LLM 提出若干候选：

* 会不会遗漏了温度？
* 会不会遗漏了历史记忆？
* 会不会存在非线性反馈？
* 会不会有隐藏的化学反应？

然后逐一验证。

这种方式可以工作，但搜索空间非常庞大，而且模型容易反复生成自己熟悉的解释。

我的想法是反过来：利用旧模型失败时留下的数学痕迹，约束新模型必须是什么样子。

例如：

如果旧模型违反守恒关系，那么缺失的部分可能需要承担一个来源、流出或储存项。

如果相同的当前状态产生不同的未来响应，那么当前变量可能不是充分状态，需要考虑历史、外部环境或隐藏状态。

如果误差只在某个变量超过阈值后突然增大，那么遗漏的关系可能具有状态依赖性、阈值性或分段结构。

这些不是直接确定 \\(Y\\) 的答案，而是缩小 \\(Y\\) 可能属于的数学结构类别。

我把这个研究方向暂时称为：

Failure-Constrained Model Discovery（失败约束的模型发现）。

这个名称只是工作概念，不是已经确认具有原创性的算法。已有的模型批评、结构发现和反例引导方法与它有相当大的重合。真正值得探索的是：能否从失败中提取足够具体的数学约束，让后续的模型构造不再主要依赖自由猜测。

下面我展开几个可以真正形成研究方法的想法。

# 一、第一步：Agent 不应该先问“缺了什么”，而应该先问“为什么调参数也救不了这个公式？”

这是我认为可以做得很扎实的一步。

假设原来的模型是：

\\[ y=f(x;\\theta) \\]

实验数据是：

\\[ D=\\{(x\_i,y\_i)\\}\_{i=1}^{n} \\]

拟合后得到：

\\[ \\hat\\theta \\]

以及残差向量：

\\[ r\_i=y\_i-f(x\_i;\\hat\\theta) \\]

一般方法会直接把残差交给 LLM：

“这是模型的预测误差，请提出一个更好的公式。”

但我认为，应该先做一个更有数学意义的测试：

这些残差，究竟能不能仅靠改变原有参数来解释？

## 1.1 参数变化能够产生的修正方向

在当前参数附近，进行一阶泰勒展开：

\\[ f(x;\\hat\\theta+\\Delta\\theta) \\approx f(x;\\hat\\theta)+J\_\\theta\\Delta\\theta \\]

其中：

\\[ J\_\\theta= \\frac{\\partial f}{\\partial\\theta} \\]

是模型关于参数的雅可比矩阵。

因此，如果只允许改变参数，模型预测的局部变化只能落在：

\\[ \\operatorname{Col}(J\_\\theta) \\]

也就是雅可比矩阵的列空间中。

直觉上：

原模型的参数只能沿着有限的几个方向改变预测。

如果观测误差主要位于这些方向中，那么重新估计参数可能就足够了。

但如果误差存在一大部分，无法由这些方向解释，就说明当前参数化在局部不足以解释数据。

可以定义：

\\[ r\_\\perp=(I-P\_J)r \\]

其中 \\(P\_J\\) 是投影到参数雅可比列空间的投影矩阵；带不同测量噪声时应使用适当的加权投影。

若：

\\[ \\|r\_\\perp\\| \\]

明显超过测量噪声能够解释的水平，我们就获得了一项证据：

问题可能不是参数取值，而是模型结构。

这个判断需要噪声模型、参数不确定性和数值条件检查。它是局部诊断，不等于严格证明所有重新拟合都无法解决问题。

但我觉得这个思路有价值，因为它把：

“模型拟合得不好。”

转变成：

“模型现有参数允许的修正方向，不能解释哪一部分偏差？”

这就为结构发现提供了更加具体的输入。

# 二、第二步：把无法解释的残差，转化为未知结构必须满足的约束

假设经过前面的检查，我们认为确实需要扩展结构。

此时先不让 LLM 直接写出：

\\[ g(x,y) \\]

而是让它分析：

新增结构需要消除什么矛盾？

例如，下面这几种情况要求的修订方向就很不一样。


| 失败特征                               | 可能缺少的结构                     | 可以用什么检验             |
| -------------------------------------- | ---------------------------------- | -------------------------- |
| 残差随\\(x\\)系统性弯曲                | 非线性项、饱和项                   | 改变输入幅度，比较响应比例 |
| 同一状态、输入下，历史不同导致未来不同 | 隐藏状态、记忆、外部未观测驱动     | 匹配当前状态，改变准备历史 |
| 某个守恒量持续出现无法解释的收支差     | 来源、损失、交换或储存项           | 控制系统边界并测量通量     |
| 同一公式在不同环境下需要不同参数       | 遗漏环境变量、机制变化或模型不适用 | 跨环境干预和参数稳定性检验 |
| 某个阈值附近出现突变                   | 状态切换、阈值或不连续机制         | 在阈值两侧密集测量         |

这里要非常谨慎。

一种残差形态可能对应多种机制。

例如历史相关误差也可能来自设备漂移，而不是系统真的存在记忆。

因此，这套机制的任务不是直接输出“发现了记忆变量”，而是产生：

\\[ \\text{Failure Evidence} \\rightarrow \\text{Constraints on Missing Structure} \\]

再根据这些约束提出竞争性解释。

我觉得你可以把这一步视为一种 Abductive Structural Diagnosis（溯因式结构诊断）。

它综合了溯因推理、模型诊断、系统辨识与约束求解的思想，但需要通过实验检验这种组织方式是否真的提高了结构发现能力。

# 三、我最感兴趣的想法：先发现“缺少了哪种信息”，再创造变量 \\(Y\\)

这可能比前面的残差诊断更重要。

我想引入一个来自 Predictive State Representation（预测状态表示） 的思想。

它的核心非常漂亮：

> 一个变量之所以有必要存在，不是因为它的名字在物理学或化学中有意义，而是因为缺少它时，系统无法充分预测未来。

这一思想已有系统辨识和预测状态表示的理论基础。

System Identification+2

## 3.1 我们甚至可以先不定义 \\(Y\\) 是什么

假设当前观测变量为 \\(X\_t\\)，但系统可能依赖过去的历史：

\\[ H\_t=(X\_0,U\_0,\\ldots,X\_t) \\]

我们可以设计两次实验，使它们在某个时刻满足：

\\[ X\_t^{(1)}\\approx X\_t^{(2)} \\]

并从这一时刻开始施加相同的控制。

但两次实验的准备历史不同：

\\[ H\_t^{(1)}\\neq H\_t^{(2)} \\]

如果未来观测的条件分布持续存在差异：

\\[ P(X\_{t+\\tau}\\mid H\_t^{(1)},a) \\neq P(X\_{t+\\tau}\\mid H\_t^{(2)},a) \\]

其中 \\(a\\) 是相同的后续干预，那么我们得到一个重要结论：

仅仅知道当前的 \\(X\_t\\)，不足以完全描述系统的可预测状态。

这时，我们还不知道遗漏的是记忆、未观测驱动，还是测量过程中的状态。

但我们已经知道：

系统缺少了某种可以区分这两段历史的信息。

我们可以尝试构造：

\\[ Y\_t=\\phi(H\_t) \\]

让它成为对预测未来有帮助的额外状态。

## 3.2 如何定义一个“好的 \\(Y\\)”？

我认为一个理想的 \\(Y\\) 应当满足两个要求。

第一，充分性。

在给定 \\(X\_t,Y\_t\\) 和未来控制条件后，更早的历史不应再显著提供额外的未来预测信息。

可以近似表示为：

\\[ I(X\_{\\mathrm{future}};H\_t\\mid X\_t,Y\_t,A\_{\\mathrm{future}}) \\approx0 \\]

其中 \\(I\\) 表示条件互信息。

第二，简洁性。

我们不希望：

\\[ Y\_t=H\_t \\]

直接把全部历史塞进新变量。

虽然这样可能提供更多预测信息，但不一定产生有意义的科学概念。

我们希望 \\(Y\_t\\) 尽可能简单、可计算，并且能够跨不同实验发挥作用。

例如：

\\[ Y\_t= \\int\_0^t e^{-\\lambda(t-s)}u(s)\\,ds \\]

这是一个带指数衰减的历史累积量。

如果这样的单一状态就能解释过去无法解释的实验差异，那么它是一个有意义的候选表示。

但它仍然只是一个预测性状态变量，不一定等于真实物理系统中的某个唯一实体。

## 3.3 更深入的数学解释

我们可以把具有相同未来预测行为的历史视为等价：

\\[ H\_1\\sim H\_2 \\]

当且仅当，在所有允许的后续实验下，两段历史对未来观测给出相同的条件分布。

那么不同的历史等价类就构成了一种预测状态表示。

这是已有 Predictive State Representation 和相关状态构造思想的核心之一。

对你的 Agent，我想到一个可以研究的方向：

让 Agent 自主寻找能够区分历史等价类的实验，再尝试构造最小的新增状态变量。

例如：

原来只有 \\(x\\)。

Agent 发现两段历史在当前 \\(x\\) 相同的条件下，未来仍有可重复差异。

然后通过多组实验排除单纯输入幅度、测量漂移等解释。

最终提出：

\\[ y\_t=\\text{过去某种作用的累积} \\]

再探索它的具体动力学。

这样得到的 \\(y\\) 就不完全是 LLM 凭知识联想出来的。

它首先是实验要求存在的一种额外信息表示。

我认为这很接近你想研究的科学概念发现。

# 四、第四个想法：不要总是问“需要增加什么”，还要问“怎样做最小的理论修补”

这个方向来自另一个领域：Counterexample-Guided Synthesis（反例引导合成）。

它的基本原则是：

一个候选被反例推翻以后，不应该只降低它的分数，而应该把失败转化成约束，使后续候选不能以相同方式再次失败。

这与已有程序合成中的 CEGIS，以及解释逻辑程序失败的研究密切相关。

Springer Nature Link+1

对你而言，可以尝试把它转化为一个科学模型修订问题。

例如：

\\[ \\dot x=f(x,u) \\]

在某组实验上失败。

我们不是直接把整个 \\(f\\) 扔掉。

而是考虑：

\\[ \\dot x=f(x,u)+\\Delta(x,u,H) \\]

其中：

\\[ \\Delta \\]

表示尚未确定的修正结构。

我们希望寻找一个复杂度尽可能低的修正，使新模型既能够解释新反例，也能够保留旧模型已经解释成功的现象。

可以把它写为一个研究目标：

\\[ \\min\_{\\Delta} \\underbrace{L(f+\\Delta,D)}\_{\\text{预测误差}} + \\lambda\\underbrace{C(\\Delta)}\_{\\text{结构复杂度}} + \\mu\\underbrace{V(\\Delta)}\_{\\text{理论约束违反程度}} \\]

其中：

* \\(L\\)：在相关实验上的预测损失。
* \\(C\\)：新增关系的复杂程度。
* \\(V\\)：对守恒、量纲、边界条件或已确认规律的违反程度。

但是，我不希望这个目标最后退化为“再做一次正则化符号回归”。

真正值得研究的是：

\\(\\Delta\\) 的搜索空间由具体失败所揭示的约束决定，而不是让 LLM 在任意公式中自由搜索。

例如，如果现有证据已经排除单纯参数变化和无历史非线性修正，那么下一轮应优先探索携带历史信息或外部状态的候选。

反过来，如果实验显示历史差异不具有稳定的预测作用，也不应强行引入记忆变量。

这里需要一个关键的安全阀：失败证据只有在噪声与模型假设允许的置信程度下，才可以用于排除某类结构；一次参数拟合失败不能永久剪除整个模型族。

# 五、如果把这些思想组合起来，我会怎样设计 Agent？

我认为系统不需要一开始就有五六个不同的语言模型角色。

可以先设计一个统一的科学研究过程，由数学工具负责检查，由 Agent 负责提出可检验的修订。

当前模型 \\(M\_0\\)

现有变量、参数、公式、成立条件

诊断失败

参数空间、残差、历史依赖、守恒与跨环境稳定性

推导未知结构的约束

缺失信息必须满足哪些性质？哪些修订方向仍然可行？

构造候选 \\(M\_1,M\_2,\\ldots\\)

新增变量、关系、机制或观测映射；保留竞争解释

选择区分性实验

冻结预测 → 获取新证据 → 淘汰、保留或修订

新的理论模型 / 不确定的等价模型集合

报告新增知识、适用范围、独立预测与尚未识别的部分

这里我想把第三步作为整个研究的核心。

不是单纯设计一个更好的公式生成器。

而是研究：

\\[ \\boxed{ \\text{Scientific Failure} \\rightarrow \\text{Structural Constraints} } \\]

能不能让这个映射变得可靠、可计算、可推广。

# 七、我建议做的第一个实验

我不建议马上在 RNA 真实案例上继续增加复杂性。

先选一个数学结构已知、但 Agent 不知道真值的受控动力系统。

你目前的仓库已经有隐藏记忆、非线性、时延等系统，可以利用这些基础设施。

但需要使用未参与方法开发的新系统和新机制组合，避免只是在已经熟悉的任务上调优。

比较四种方法：


| 方法        | 输入给 LLM 的信息                          | 要检验什么                 |
| ----------- | ------------------------------------------ | -------------------------- |
| A：直接生成 | 原模型、数据、普通残差                     | 基础模型发现能力           |
| B：数值反馈 | 加入详细残差、参数拟合与预测检查           | 现有数值反馈的作用         |
| C：结构诊断 | 加入参数可修复性、历史/环境/守恒等检查结果 | 结构性失败证据是否有增益   |
| D：约束驱动 | 将诊断结果进一步转化为候选修订约束         | 失败约束是否真的引导新结构 |

保持基础模型、可见信息权限、工具和预算尽可能可比。

最核心的评测不应该只是最终 NMSE。

还应测量：

1. 缺失结构类型识别率。 Agent 是否正确识别需要非线性、记忆、隐藏驱动等结构，而不是只生成更复杂的任意表达式？
2. 新增结构的有效率。 提出的新项有多少真正改善独立干预预测，而非仅改善训练拟合？
3. 错误引入 \\(Y\\) 的比例。 当原模型其实足够正确、只是数据噪声较大时，Agent 是否会凭空增加变量？
4. 发现效率。 找到一个有效结构需要多少模型调用、计算和实验？
5. 结构等价性与可识别性。 是否找到了行为等价的解释，还是错误地宣称唯一恢复真实机制？

我尤其想强调第三项。

一个真正可靠的理论发现 Agent，不仅需要知道何时加入 \\(Y\\)，还应该知道何时不需要加入 \\(Y\\)。

这可能成为与你现在仓库里那些“重复提案”和“任意扩展结构”失败现象直接对应的评价指标。
