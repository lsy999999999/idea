# 阶段一失败后的处理方案

日期：2026-11-03。依据：阶段一报告、冻结协议、原始候选、生成配置、实际拟合代码及已公开的新观测。

本次完成事后审查和观测见证计算；没有新增研究模型调用，没有修改冻结实验，没有把组织者修补计入 agent 成功。原阶段一仍为未通过。

## 1. 当前结果应该怎样解释

当前主要问题是候选构造接口尚未可靠，生成控制主要停留在提示与名额配置；同时，成功运行的候选也暴露了具体科学表示不足。尚不能判断结构约束方法优于或劣于自由生成。

| 分母 | 结果 | 含义 |
|---|---|---|
| 9 个原始提案 | 7 个数值模型、2 个信息请求 | 不能把它们等同为 9 个完成科学验证的模型 |
| 7 个数值模型 | 2 个完成拟合与评价 | 2 个超四参数上限，2 个引用不存在的参数，1 个数学树非法 |
| 2 个信息请求 | 0 个可执行 | 请求的内部状态传感器没有操作接口 |
| 2 个可执行模型 | 0 个通过独立验收 | R2 不使用历史；R3 使用历史均值但不足以解释新条件 |

其中“超参数数量上限”是协议违规，不代表公式没有科学价值；未声明参数和非法树是实现失败。两类都计入原始失败，但修复方式不同。

六次调用中，只有两次首轮生成和一次候选修订。该修订收到的主要是执行错误，随后没有再进行一次“获得有效数值失败反馈—修改结构”的生成调用。因此，这轮尚未充分测试连续科学修订能力。

## 2. 先完成候选构造修复

### 2.1 用一份模型定义产生全部表达

让模型提交紧凑的命名定义和参数声明，由编译器产生表达式树、参数索引、执行代码和公式展示。参数通过名称绑定，不要求模型同时维护 p[i]、参数表和自然语言中的三份对应关系。

长篇递归 JSON 树可以作为内部表示，不必让模型一次手写完整嵌套树。若继续采用结构化解码，需实测服务支持的模式确实约束叶节点、一元和二元算子的元数；本地 schema 通过检查不等于远端解码已经遵守。

编译时检查：符号是否存在、参数引用、算子元数、标量/向量形状、输出是否为共同读数、时间可用性、可判断的单位关系和数值定义域。说明文字从实际模型导出；不能让“包含历史二阶矩”的文字覆盖一个没有平方运算的程序。

对不完整或含歧义的科学表达，返回明确错误给模型修订，保留原提案与修订成本。不能由组织者默默补入科学项。

### 2.2 调整四参数上限的角色

原模型已有截距、当前驱动和等待时间三项。新增一个带时间尺度的历史项通常还需要至少两个参数，因而自然的扩展会超过四参数上限。原限制事实上同时考验了结构发现和强制压缩。

下一份协议建议统一允许至多八个命名参数，以总拟合残差调用上限控制计算资源，并记录完整模型复杂度及有效参数数。该调整事先对两组固定，不能按某个候选结果临时放宽。独立 RMSE 阈值保持 0.06，仍用独立预测和复杂度判断额外参数的价值。待接口稳定后再单独研究紧预算下的压缩能力。

### 2.3 根据可用工具安排提案

当前装置支持改变驱动序列、等待时间并读取响应，未提供“直接测内部 z”的传感器。移除为不可用测量固定保留的提案名额；允许模型报告需要什么额外能力，但将这种报告与可立即执行的实验分开。

真实的测量扩展能力应放到另一个提供可组合获取接口的任务中评价。当前任务优先围绕已有记录和可执行干预推进。

## 3. 将已有新观测转成下一轮开发依据

初始约束 C1 只说明：在受控前提下，当前 (u,h) 不足以解释历史组间差异。任何能区分正负历史的均值特征都可能通过这一关；它没有保证找到充分表示。

本次只用两份已经公开的新实验记录计算见证，结果见 [OBSERVED_WITNESS_AUDIT.json](OBSERVED_WITNESS_AUDIT.json)。以下是组织者事后诊断，供下一轮开发使用，不计作研究 agent 的自主约束发现。

### 3.1 历史数值相同，顺序不同，响应仍不同

E1/E3 具有相同 u、h、时间网格与历史数值集合，只改变历史数值所在的时间位置。平均读数差的绝对值为 0.297057。

在共同稳定观测和共享参数等前提下，任何仅通过排列不变摘要使用历史的模型，都对这两个条件预测同一个值。这包括历史均值、总和、方差和任意阶无序矩，无论其后的函数多么复杂。

对这八条已观察读数，强制两组共享预测值时的最低 RMSE 为 0.148841。这个界只针对该对照组，不能直接当作整个最终测试集的下界。E5/E7 同样只改变排列，对应界为 0.206559。

下一步搜索应允许保留时序或相对时间的信息。限制的是完整模型缺乏区分能力，不是禁止均值等统计量作为模型的一部分。

### 3.2 完全忽略等待时间无法解释已有记录

E9/E10 的 u、历史序列、时间网格和 dt 相同，等待时间不同，平均读数差为 0.242864。对这八条记录，任何预测完全不随 h 改变的模型，其最低 RMSE 为 0.121623。R3 正是这一类。

这条见证要求模型能表达对应的 h 变化，尚不指定其函数形式。

### 3.3 历史效应本身随等待时间变化

E1/E3 在 h=0.5 的历史对比差为 0.297057；E2/E4 在 h=2.2 的相同历史对比差为 0.139380。两个差值相差 0.157677。另一组交叉对比 E5/E7 与 E6/E8 得到 0.222112。

若模型严格可加分离为 O=A(u,h)+B(history,times,dt)，这两个历史对比差应相同。假设每条读数误差绝对值不超过 0.015，差中差的噪声上限为 0.060。因此这些记录提供了反对严格可加分离的证据，支持探索历史与等待时间的联合作用。

这里仍须区分“精确机制在有界测量噪声下成立”和“允许一定模型误差的近似预测”。上述两组差中差给出的四组平衡数据 RMSE 下界分别仅为 0.039419 和 0.055528，单凭它们不能排除所有满足 0.06 容差的近似可加模型。因此，下一轮先将联合作用作为搜索优先级；如需硬剪枝，应显式纳入允许的模型失配，而不是只使用传感器噪声界。

这些见证不指定指数核、衰减常数或目标方程。新模型可以使用不同的时间表示、状态模型或非可加函数，只要能在共同观测上解释证据。

## 4. 生成控制需要从配置文字推进到构造操作

现有 G 在调用前改变了提示中的操作名额，但没有构造器阻止最终程序忽略历史。修订 R2 再次输出不含历史的程序，是这一缺口的直接表现。

第一版可让模型逐步提交变量定义和模型组合操作，构造器维护信息依赖与可识别的对称性。例如，在稳定观测分支中，若完整表示仅包含当前输入和排列不变的历史摘要，则标记尚未满足顺序见证的区分义务，引导下一次构造补入可用的时序信息。

必须保留三条边界：

- 语法上出现 history 不保证实际依赖，抵消项和零系数仍需共同测试。
- 静态分析无法确认的程序标为未知，不因分析器能力有限而硬拒绝。
- 如果已经生成完整公式后才检测失败，仍计为生成后筛选。只有构造过程中的操作变化可支持生成控制的机制主张。

实现修复对 F/G 共用；观测导出的结构控制只在 G 启用。不能把更好的参数绑定和语法解码计作结构约束的优势。

## 5. 下一轮的最小执行顺序

建立新的恢复运行目录和冻结协议。原阶段一、原候选及其评分保持原样。

1. **离线验收接口。** 用通用合法和非法表达检查命名参数、元数、形状、单位及公式展示。用当前失败样本确认错误能准确定位；不改写它们的历史成绩。
2. **一次只推进一个完整候选。** 保持研究模型 gpt-6-luna / low，降低一次调用中同时构造三套模型、解释和实验方案的负担。
3. **有限的技术修订。** 反馈编译器错误，最多允许一次修订并记为新的提案。无法运行时停止该候选，不无限重试。
4. **至少一次真正的科学修订。** 对合法候选返回开发拟合结果、未解释的观测对照和不确定性，要求修改变量定义或完整模型。记录具体哪项证据改变了哪项结构。
5. **冻结新预测后获得新观测。** 在事先固定的调用与工具预算内，允许据运行中新证据再进行一次科学修改，最后才打开新的独立测试集。

建议总研究调用仍不超过六次，将调用优先用于候选—工具反馈—修订链。编译修复、科学修订和结果总结分别计数，不为了凑满预算增加调用。不改变模型和 reasoning 设置来掩盖接口问题。

当前案例已经用于提示和开发，包括给过指数历史示例。继续在此案例取得成功，只说明开发流程跑通。干净测试应使用冻结方法后的新机制或新组合，移除答案相关示例，并避免通过回灌旧候选重新引入示例信息。仅更换噪声种子或最终隐藏记录不能建立新的概念发现证据。

## 6. 什么时候进入下一阶段

先满足三个条件：候选可稳定编译且文字与程序对应；存在一条依据数值/实验反馈发生的真实结构修订；提交的候选通过新冻结的独立预测要求。

这说明流程具备可评测性，不说明 G 已有优势。接着在新开发快照上做一个小规模 F/G 配对，检查相同证据、语法、筛选和总预算下，G 是否改变了原始候选结构并减少无效搜索。只有这一结果值得继续，才开展计划中的 36 次搜索。

结构约束推导可靠性、生成控制收益和科学预测有效性分别报告。原六次调用不足以认定模型能力不足、方法无效或方法有效。
