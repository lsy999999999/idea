# 研究计划：通过实验约束发现新变量与新模型

更新日期：2026-11-03  
当前阶段：明确研究目标，验证核心机制，再决定是否扩展系统。

## 1. 我们要完成什么

我们希望构建一个科学研究 agent：当现有模型无法充分解释观测时，它能够判断需要修改什么，自主提出此前未被指定的量或关系，并通过新的证据检验修改后的模型。

已有模型写作：

$$
O=f(X;\theta).
$$

其中，$O$ 是待解释的观测，$X$ 可以包含任意数量的变量。系统可以重新估计参数，也可以提出：

$$
O=g(X;\phi)
\quad\text{或}\quad
O=g(X,Y;\phi).
$$

**新量 $Y$ 的定义与新模型 $g$ 的形式都属于发现结果。$g$ 可以整体替换 $f$，不要求保留原公式的结构，也不要求每次都增加新变量。** 动态方程、隐式关系和概率模型可以作为后续扩展的表达形式。

系统需要支持三条研究路径：

| 路径 | 问题所在 | 预期行动 |
|---|---|---|
| 修改模型 | 现有信息足够，参数或函数形式不合适 | 重新拟合、修改结构，或整体重写模型 |
| 构造表示 | 所需信息已经存在于原始记录中，但没有被当前表示利用 | 构造新的变量、对象或时间表示，并联合搜索新模型 |
| 补充信息 | 现有记录无法区分竞争解释 | 提出可执行的新测量或干预，再更新变量与模型 |

项目的最终输出是一套有证据支持的解释：新量如何定义和获取、模型如何运行、它解决了哪些原有困难、在哪些新条件下通过了检验，以及哪些解释仍无法区分。

## 2. 本阶段的核心研究问题

我们首先研究：

> 能否从实验冲突中推导出有明确前提和适用范围的结构限制，将其转成生成前的搜索操作，从而减少缺乏所需表达能力的候选，并保留发现新变量与完整重写模型的能力？

工作假设是：自然语言批评容易停留在“拟合不好”“可能存在记忆”等描述上。更严格的候选测试可以改善筛选；本项目进一步检验，证据支持的结构限制能否在生成前改变候选语言、修订操作和搜索预算，从而减少相同失败的重复出现。

拟研究的方法集中在三个环节：

1. **形成结构限制：** 从观测关系出发，核查推理前提，明确哪些指定模型类别缺乏解释该关系的能力。
2. **修改搜索：** 将结构限制落实为生成器的表示、操作或预算改变，并保留独立的候选测试。
3. **修订约束：** 当原证据或前提发生变化时，降低约束强度或撤回约束，恢复仍然可行的方向。

模型批评、预测状态表示、反例引导合成和主动实验已有研究基础。本项目的方法贡献需要通过专项查新及同证据、同预算的比较来建立。检索、排序、数值拟合采用合适的成熟工具；研究重点是上述三个环节如何共同改善发现过程。

## 3. 一个研究回合如何运行

### 3.1 确认当前困难

系统接收研究目标、当前模型、原始数据及元数据、可用测量和干预接口，以及预算。

先检查数据与计算是否对应预定问题，包括单位、时间窗、输出列和观测对象；再检查参数估计是否充分，是否存在明显的收敛或约束问题。之后记录：

- 哪些条件下预测失败，误差和不确定性多大；
- 偏差是否随输入、历史、环境或对象变化；
- 当前模型在哪些条件下仍然有效；
- 哪些现象可能来自测量过程或数据不足。

模型失配通过独立预测检查、重复实验或明确噪声模型下的校准来判断。校准模拟需要包含“生成数据—重新拟合—计算诊断”的完整过程。

在同数据、固定权重、无正则且无活跃参数约束的最小二乘内部驻点，残差已经与参数雅可比列空间加权正交，因此不把残差正交投影作为参数问题与结构问题的新增鉴别器。雅可比可用于局部敏感性分析，以及判断候选新项是否难以与已有参数区分。

### 3.2 独立模块：从观测证据推导结构限制

区分三类约束及其主要用途：

| 类型 | 表达的内容 | 主要用途 |
|---|---|---|
| 观测约束 | 候选需要解释哪些可重复的实验关系 | 形成候选测试和预测要求 |
| 结构约束 | 在明确前提下，哪些数学结构无法满足观测要求 | 修改生成空间、允许的修订操作或搜索优先级 |
| 理论约束 | 量纲、守恒、边界条件等关系及其适用假设 | 在前提成立的范围内限制候选 |

三类标签描述不同作用，可以重叠。约束类型与执行强度分别记录：守恒关系也可能转成结构限制，但理论来源本身不意味着应当无条件严格执行。

设置一个独立的结构约束推导模块，输入为观测证据、当前模型假设、可用检验和已核实的数学关系。输出包含：

| 字段 | 含义 |
|---|---|
| 证据 | 实验协议、原始结果、效应大小与不确定性 |
| 推理前提 | 状态匹配、参数共享、解的唯一性、时间与控制对齐、测量和噪声条件 |
| 推导依据 | 从这些前提到候选类别限制的数学理由，或明确标注的统计证据；启发式单独记录 |
| 作用范围 | 哪个参数实例、模型族、变量表示或观测映射受到限制；适用于什么条件 |
| 结构限制 | 哪类表示缺乏所需区分能力，哪些解释仍然可行 |
| 生成操作 | 如何改变模型语言、修订操作或预算分配；与生成后的拒绝分开记录 |
| 独立检验 | 任一新候选如何接受同一观测检查 |
| 撤回条件 | 哪些前提变化、新证据或实现修复会使限制失效，并恢复对应搜索方向 |

第一版采用“提出结构限制—核查前提与推导—生成可执行搜索操作”的流程。LLM 可以提出限制，经过数学规则、可执行检查或新实验核查后才能提升强度。无法核查的理由作为搜索建议，不自动硬剪枝。数值拟合失败本身不构成整个模型族不可行的证明。

**例子：历史差异何时可以改变搜索类别。** 对固定且共享的确定性模型 $\dot X=F(X,U,t;\theta)$，若初始状态、初始时刻、后续输入和参数相同，且初值问题具有唯一解，则两次预测轨迹相同。自治不是必要前提；显含时间的模型需要时间对齐。局部 Lipschitz 等条件可支持解的唯一性。

如果实验在已核查的条件下仍显示可重复差异，就会对“当前记录 $X$ 已构成充分状态、参数与驱动共享、观测过程稳定”的模型类别提出冲突。系统应记录究竟拒绝了哪些联合假设，保留新增状态、外部条件、时间依赖和测量状态等不同解释。

实际观测匹配通常只是近似匹配，微小初态差异可能被动力学放大。应先控制或量化匹配误差、测量噪声和响应敏感性；无法给出足够界限时，保留为软限制或请求进一步实验。不能从两条近似匹配轨迹直接排除所有无历史的非线性模型。

由观测得到的候选测试始终保留；结构限制是否可靠及是否实际改变生成，分别评价。检验阈值、容差和最大检验次数在运行前固定，避免反复尝试造成错误排除累积。

### 3.3 检索结构、定义和测量方法

设置一个检索 agent，围绕尚未解决的差异开展三类检索：

1. 目标领域已有的解释、反例和适用边界。
2. 其他领域处理相似数学或实验结构的方法。
3. 候选新量的计算、测量、识别和区分实验。

每条有用材料交付：来源与证据位置、机制或数学结构、成立条件、目标领域中的对应关系、候选量的获取方式，以及可以检验迁移条件的实验。

检索得到的知识用于构造和约束候选。目标系统中的有效性由数据与实验检验。发现目标问题已有解释时，记录为已有知识的应用或重发现，并据此调整原创性判断。

### 3.4 联合生成变量与完整模型

每个候选至少包含四部分：

| 部分 | 必须交付的内容 |
|---|---|
| 量的定义 | 新量的数学定义、单位、时间可用性；没有新量时明确记录 |
| 完整模型 | 可运行的方程或程序、参数、预测对象与适用条件 |
| 获取方式 | 由已有记录计算、通过潜变量推断，或需要新增测量 |
| 区分实验 | 与主要竞争解释在哪些条件下产生不同预测 |

生成过程中同时保留参数调整、局部修改和整体重写的可能性。候选是否包含新变量，由证据决定。

结构约束通过具体搜索操作接入生成器。例如：在依据充分且范围明确时，暂时禁用“保持当前输入与状态集合、仅替换无历史函数项”的修订操作；启用增加状态、记录外部条件或重构观测映射的分支；前提尚未确认时则只调整这些分支的预算。完整重写始终保留，但生成的新模型也需满足适用的结构限制。

这一步必须发生在候选生成或构造过程中。LLM 先完整生成、再被静态检查器拒绝的候选，仍计作一次原始提案和一次生成后筛选，不能记为“已通过约束避免生成”。每个回合记录生成配置、操作集合、预算变化和全部原始提案，以核实约束是否改变了搜索。

候选类别依据实际信息依赖和模型语义识别，不只看变量名。无法可靠分析的程序标为未知并接受检验，不能因分析器不支持就直接断定其结构不可能成立。模型语言使用可组合的数学与观测原语，并保留扩展接口，避免只有预先列好的机制名称可选。

若 $Y$ 从历史构造，需要定义初始化、更新方式和未来预测。若信息没有记录，系统应提出新测量请求；不能仅通过给隐藏量命名来补足信息。潜变量可以从观测推断，但必须受到跨样本或动态规律的约束，并接受新条件预测检验。

完整模型的复杂度、变量获取成本和预测质量共同参与比较。旧模型已经解释的现象通过回归检验保留，不固定保留原公式的项。

### 3.5 选择下一项行动并更新判断

候选经过基本执行和数值检查后，使用排序或模型比较组件分配预算。可选择继续拟合、重新组织数据、检索、补充测量或执行干预。

实验优先考虑三类价值：区分现有候选、降低关键参数或变量的不确定性、检查所有候选共同忽略的现象。排序依据包括成本、可执行性和预期研究价值，不能只依据文字评价分数。

实验前保存各候选预测；实验后将结果对应到具体的变量定义、模型关系、测量方式和约束。原因不明时保留竞争解释。达到验收要求、预算耗尽或当前工具无法区分解释时停止，报告完成的发现及受阻原因。

## 4. 新变量与新模型怎样验收

一个候选通过验收，需要完成以下检查：

1. **可执行：** 变量可以按定义获取，模型可以运行，预测对应实际观测。
2. **解释原有困难：** 能处理触发修订的实验关系，并在共同观测目标上比较。
3. **独立预测有效：** 在未用于构造、拟合和选择候选的数据或干预上达到预先规定的要求。
4. **复杂度有价值：** 新增变量或结构带来的收益足以支持其计算或测量成本；原模型足够时允许不修改。
5. **结论范围明确：** 区分预测表示、机制解释和唯一物理实体，保留尚无法区分的等价模型。

对历史状态，第一版在预先规定的干预族和预测时域上检查：加入更长历史是否仍带来超过实用阈值的预测收益。使用独立数据、区间和功效评价近似充分性，不以条件互信息估计值接近零直接证明全局充分。

模型间使用共同原始观测或共同实验预测进行比较。不能把不同维度、不同尺度的观测摘要拟合误差直接放在同一个排行榜上。

## 5. 现在按什么顺序做

### 阶段一：完成一条从证据到搜索的完整实例

先选一个开发案例，完整走通：

> 当前模型失败 → 确认观测关系 → 核查结构推导的前提 → 形成类别限制 → 改变生成操作 → 构造候选并独立检验 → 冻结新预测 → 获得新证据 → 保留或撤回限制。

交付五项产物：实验记录、结构推导及前提检查、生成器修改前后的配置、全部原始候选与筛选记录、新实验预测与结果。

同时确认近期相关方法是否已经实现相同的证据到约束转换。重点比较模型批评、MDA/BMD、预测状态与主动系统辨识、反例引导合成及失败约束程序学习。已有查新作为起点，专项比较落实到操作规则和实验条件。

本阶段的验收点是：约束确实改变了一项生成前的搜索操作，且独立测试仍检查候选是否解释现象；证据无效时能够撤回；全过程不依赖组织者提供真实机制标签。只有生成后拒绝增加，不满足此处的生成机制验收。

### 阶段二：比较相同证据下的两种修订方法

准备六类受控开发案例，用于诊断能力和方法机制评测。真实机制仅对评测程序可见；这些案例不单独支持开放式结构发现的结论：

| 案例 | 要检验的行为 |
|---|---|
| 原模型足够，观测带噪声 | 是否无依据地扩展模型 |
| 原模型形式正确，但参数拟合不充分 | 是否先解决估计问题 |
| 当前变量足够，但函数形式错误 | 是否能整体重写模型而不强加新量 |
| 信息存在于历史或原始记录中 | 是否能定义有用的新表示 |
| 差异主要来自测量过程 | 是否错误地把测量现象解释为系统新机制 |
| 信息未记录，但允许补充测量 | 是否能提出有效的信息获取请求 |

先对每类案例构造一个冻结的证据快照，并由待测模块生成约束包，保留其中正确、不确定和错误的推导。评测程序审计其有效性，不能用真实机制替换或补全推导。约束推导质量单独报告；随后把完全相同的证据与约束包提供给两种搜索方式：

| 方法 | 共享输入 | 如何进行模型修订 |
|---|---|---|
| F：自由生成与统一筛选 | 当前模型、数据、诊断结果、检索材料、同一约束包 | 可自由利用这些信息，但不强制改变生成语言和修订操作；生成后接受统一检查 |
| G：结构约束引导生成 | 与 F 完全相同 | 将约束接入生成语言、修订操作或搜索预算；生成后接受与 F 相同的检查 |

首轮每类使用三个配对随机种子，共 18 对、36 次有限搜索。每次最多产生三个原始候选，使用相同的拟合上限和总资源上限。静态检查拒绝的原始候选也占用名额。共享约束包的成本计入两组，生成控制的额外成本计入 G；F 可将对应预算用于分析或修订。该比较检验在相同信息和筛选标准下，生成控制是否提供额外收益。

这一轮以冻结证据下的一次有限修订为比较单位。候选提交后，在同一组隐藏实验上评价；需要额外测量的候选同时评价其预先提交的测量请求。由评测程序判断该请求是否有助于区分解释，结果不回灌本轮搜索。

18 对比较用于定位失败和初步收益。下一阶段再加入只获得原始诊断、不获得显式约束包的方法，测量结构推导与生成控制的完整效果；不能把更严格的最终筛选单独计为生成机制的收益。

### 阶段三：运行连续发现过程

第二阶段出现值得继续调查的收益后，再开展多轮自主研究。第一版每条轨迹最多四轮，每轮最多提交三个候选、发起一次新实验或测量请求。

各方法获得相同初始信息、工具权限、可检索文献和总预算。后续证据可以因各自实验选择而不同，这是连续研究能力比较的一部分，应与第二阶段的同证据比较分别报告。

运行前固定最大模型调用、数值计算、检索和测量额度，并记录实际消耗。检索失败、实验不可执行和预算耗尽都计入结果。

### 阶段四：开放式结构发现与真实案例

开发流程稳定后，冻结方法、提示、约束规则和评价标准，建立独立于六类诊断案例的发现测试。分开报告两种能力：

- **未见组合的发现：** 基础因素可能出现过，但它们的耦合、层次或观测关系没有用于方法开发。例如环境调节隐藏状态，同时仪器存在非线性观测变换，要求联合修改状态与观测模型。此项检验组合泛化。
- **未见结构的发现：** 使用没有参与约束规则设计的新机制族或新表示需求。候选答案不能限制为六类标签或固定机制菜单。预先检查工具与通用模型语言能够表达可行解，并记录允许的表达范围。此项检验该范围内的结构外推。

联合机制例子只作为开发说明。正式测试重新设计耦合方式和观测关系，冻结后不根据失败补写规则；任何补写都将对应案例转为开发数据。仅改变参数、随机种子或变量名称不计作新的结构任务。

每个开放案例运行前，由评测程序检查：可用干预、重复次数和预算下，关键竞争解释是否能够被区分。对于动态状态与观测非线性耦合的例子，可提供可访问的环境干预、传感器校准或参考观测，使 agent 有机会区分原因，而不直接提供正确结构。只知道模拟器真值，不足以证明任务可识别。

对存在原则性等价或预算内区分能力不足的案例，分别评价预测、请求有效补充信息和报告等价解释的能力，不将未恢复唯一真机制一律计为失败。真实案例和受控案例分开报告。

真实案例需要明确原模型、实际困难、可获得数据和可执行的验证方式。历史重发现使用早于目标成果最早公开日期的检索材料，并单独说明该控制无法消除预训练知识。世界范围的新发现需要额外的原创性检索和独立科学验证。

## 6. 衡量什么，以及什么时候继续

| 指标 | 定义 |
|---|---|
| 独立预测质量 | 隐藏实验或新条件下的预测误差、分布预测质量及不确定性 |
| 有效修订率 | 候选解决原有困难并通过独立检验的比例 |
| 无必要扩展率 | 原模型足够时，仍引入没有独立收益的新量或结构的比例 |
| 错误约束率 | 约束与其证据或适用前提不一致的比例 |
| 可行模型误剪率 | 在可审计的受控条件下，正确或行为等价的可行候选被错误排除的比例 |
| 重复失败率 | 已有证据能够识别的同类失败再次出现的比例 |
| 生成前改变 | 约束实际修改了哪些语言规则、修订操作或预算，以及这些改变的适用范围 |
| 原始提案违约率 | 所有生成后筛选之前的提案中，违反已支持结构限制的比例；包括被静态检查拒绝的提案 |
| 筛选后有效率 | 通过统一筛选的候选中，独立预测有效的比例；与原始提案指标分开报告 |
| 发现成本 | 达到同一独立预测要求所需的调用、计算、检索和测量成本 |
| 结论匹配度 | 是否把预测改善、变量识别和唯一机制恢复区分清楚 |

原始真模型、构造的等价候选和可验证的参数解用于受控误剪审计。对于无法穷尽搜索的模型族，记录“未找到可行参数”，不将其直接记为整个模型族不可行。

各案例的实用误差阈值、测量容差和检验规则在查看方法结果前确定。阶段二首先查看配对结果、任务差异和不确定性：扩展连续实验需要看到生成行为确实改变，收益表现为更好的有效修订或更低成本，且没有新增的实质误剪问题。若收益完全来自生成后多拒绝候选，则只支持筛选器改进。

若收益只体现在文字质量或训练拟合，修正方法；若加速搜索同时增加误剪，修正约束的证据要求与使用强度；若现有强方法已经解决目标案例，进一步定位尚未解决的科学困难。

## 7. 我们期望达到什么

### 近期：证明一个具体机制是否有效

完成可审计的观测到结构限制转换，并确认它在相同证据、约束信息和筛选标准下是否改善生成过程。交付独立的结构约束推导模块、生成控制原型、配对结果和具体失败分析。

### 中期：形成完整的新量与模型发现能力

系统能够根据证据选择重写公式、构造表示或补充测量；自主生成量的定义及其作用模型；通过多轮区分实验改进解释，并正确处理无需扩展和暂时无法识别的情况。

### 论文目标：建立可归因、可复核的方法贡献

提出明确的结构约束推导与生成控制规则，说明其改善发现的条件、代价和失败边界；分别通过诊断任务、未见组合和未见结构任务验证能力，利用统一筛选的机制对照区分生成与筛选收益。真实科学案例用于检验这种能力是否能推动一个实际问题的解决。

## 8. 实现与记录原则

- 第一版使用一个研究控制流程、一个明确的检索接口和数值/实验工具；角色数量根据实现需要安排，评测围绕方法机制。
- 生成模型、可见信息、工具权限和预算在实验前固定。模型身份记录为实际请求和返回信息，不据代理服务名称推断底层权重。
- 分开保存拟合数据、可供反馈的开发证据、运行中的新实验和最终隐藏测试。被用于反馈的观测不再作为独立测试证据。
- 保存每个初始候选、修改分支、约束版本、来源、预测和执行结果。已冻结的历史实验保持原样。
- 原有模拟器作为开发基础设施；新测试中的机制和答案不进入 agent 可见文件、诊断标签或检索材料。
- 约束有独立的实现检查，特别关注单位、时间、观测映射和参数对应关系，防止计算错误变成后续搜索规则。

## 9. 已有文献与本计划的关系

以下工作用于定位能力重合、选择比较机制和完成专项查新：

| 工作 | 需要重点比较的内容 |
|---|---|
| [LLM-SR](https://arxiv.org/abs/2404.04627) | 方程结构生成、参数拟合与数值反馈 |
| [AI-Newton](https://arxiv.org/abs/2504.01538) | 概念定义、测量程序、已有规律的推广 |
| [MDA](https://arxiv.org/abs/2608.09696) | 预测检查、隐藏状态、模型空间扩展与实验选择 |
| [BMD](https://arxiv.org/abs/2610.25747) | 残差与信念反馈、模型族搜索及信息驱动实验 |
| [OptScientist](https://arxiv.org/abs/2610.28562) | 文献引导的变量构造与优化规律发现；其优化表示不是本计划预设的模型主干 |
| [IRIS](https://arxiv.org/abs/2510.09217) | 检索、缺失变量提议与变量集合扩展 |
| [Learning programs by learning from failures](https://doi.org/10.1007/s10994-020-05934-z) | 失败如何形成可执行搜索约束，以及逻辑反例与带噪声实验的区别 |

MDA、BMD、OptScientist 和 IRIS 在本计划中按已查阅的公开预印本版本讨论。进一步专项查新应覆盖预测状态与因果状态构造、主动系统辨识、模型失配检验及反例引导合成，并对照具体约束操作，而不仅比较系统流程图。
