# 开放变量与公式发现：查新和原型设计

日期：2026-11-03。状态：设计建议，尚未得到用户采纳；本轮没有启动模型实验，也没有修改既有冻结实验。

## 1. 目标与查新结论

用户的核心任务是：从已有解释 z=f(x) 出发，自主发现此前没有指定的量、参数依赖或函数结构，并形成 z=g(x,y)。g 可以整体替换 f；不限制为 f(x)+修正项，也不要求每个成功解都增加 y。x 可以是任意变量集合，y 可以是向量、派生量、内部状态或待测量量。原公式是比较起点，不是不可更改的骨架。

查新结论：这个大方向已有直接研究，不能把“检索＋提出新变量＋方程搜索＋实验反馈”作为新的论文贡献。最新的重要重合是 OptScientist；此外 AI-Newton 已经明确记录概念的测量程序，MDA 已经涉及隐藏状态和观测表示，IRIS 已经从检索材料扩展变量集合。下述设计是可实现的研究原型，潜在贡献必须通过具体失败定位和强基线比较建立。

### 三个必须保留的重合事实

1. OptScientist 的附录 B.3.2 给出具体变量构造：期望收益、风险/歧义变换、滞后获得收益和放弃收益；A.2 明确变量不能依赖当前目标或验证/测试信息。我们的变量定义约束不是独有做法。其核心模型面向优化规律，作者在 §6 讨论这一结构假设的范围。不能仅因我们支持另一类方程，就认定产生了新方法。
2. AI-Newton 明确用实验程序定义质量等内禀概念，并比较不同实验定义得到的概念。将“新量必须能够测量”作为原则并非首次提出。
3. MDA 已经学习或选择观测摘要、随候选池变化重新学习，并讨论摘要可能丢掉区分机制的信号。因此“我们联合调整模型和表示”也不足以单独区分。

## 3. 可执行的原型设计

### 3.1 输入与候选对象

输入包括研究目标、初始模型 f、原始数据/元数据、可调用工具与测量/干预接口，以及预算。保留原始过程信息，避免只给组织者挑好的特征表。工具可以说明传感器或记录的物理含义，但不要直接提供答案变量及其正确变换。

每个候选以 C=(h,g,m,e) 表示：

- h：量的定义。可以是原始记录的变换 y=h(r)，也可以是潜在状态更新规律。没有新量的候选允许 h 为空。
- g：完整的新模型。允许整体替换 f，包括静态函数、动态方程、隐式关系或优化表达；第一版只实现其中一种模型族接口，避免无限制程序搜索。
- m：获取或约束该量的方式。区分直接测量、由已有记录计算、由潜变量推断获得；注明单位、时间窗、误差和成本。
- e：区分候选与已有解释的检验。注明实验条件、各候选预测、失败后应修改的部分。

这里的四元组是工程接口，不是形式理论或已验证的算法贡献。潜变量可以依据观测拟合；问题在于是否只为每个样本分配自由值，以及是否能对新实验作受约束的预测。不能将禁止一切目标相关推断误用为对合法潜变量模型的排除。

### 3.2 每轮具体行动

1. **形成差异记录。** 拟合并检查当前模型，记录失效条件、残差时间/分组结构、测量重复性和已有成功范围。先排查基本实现/数据问题，保留多个原因，不硬判定缺失变量。
2. **定向检索。** 检索 agent 同时查目标领域已知解释、其他领域的相似机制、以及测量/识别方法。查询使用实际失效结构，例如历史依赖、输入顺序影响、尺度不一致；不预先告诉它正确的机制名称。
3. **生成不同结构的候选。** 每轮保留少量真正不同的机制分支，并至少保留一个不加变量、只更改函数结构的对照。检索提供备选结构和约束，不能锁死 g 的形式。
4. **编译与廉价筛选。** 将候选转成可运行的变换、模型与检验。做单位、时间可用性、泄漏、可识别性和等价结构检查；在相同数据划分上拟合。不同观测表示的模型必须回到共同原始目标或共同实验预测比较，不能直接比较不同维度摘要的拟合误差。
5. **决定下一笔预算。** 使用现成排序/模型比较方法，选择继续拟合、重读原始记录、检索、测量或干预。信息增益在模型池内有效，还需保留检查所有候选共同失配的实验预算。
6. **更新具体判断。** 结果应对应到变量定义 h、模型关系 g、获取方式 m 或检验设计 e；原因不明时保留竞争诊断。冻结每条分支和修改原因，允许停止、放弃或报告当前无法区分。

检索 agent 的输出必须包含：来源和精确证据位置、原领域的数学结构、成立条件、目标领域的对象映射、对应的新变量/变换、可执行获取方式，以及该结构在目标问题上可能失败的条件。主题相似和引用数量不作为机制有效的证据。

查已有工作用于排除已知答案或定位贡献；获取目标系统的独立数值证据用于检验候选。这两种用途分别记录，防止把找到一篇相似论文当成已经验证目标模型。

### 3.3 一个仅作说明的例子

旧模型 z=f(u) 在当前输入相同、历史不同的条件下产生系统偏差。候选可以包括：(A) 更灵活的静态 g(u)；(B) 动态状态 dy/dt=a*u-b*y，z=g(u,y)；(C) 测量延迟或漂移；(D) 某个外部条件调节响应。

系统自行提出顺序、间隔或恢复实验，比较候选的事前预测。B 若胜出，还需检查 y 能否通过独立记录、代理测量或跨实验的一致关系被约束。这个例子演示接口，不是新科学机制，也不是建议把该答案写进测试提示。

## 4. 可能研究什么，以及如何决定是否值得做

候选研究假设：普通文献检索能让 agent 说出合理机制，却未必能把机制转成目标系统中可区分的量与模型；依据具体失效构造查询、检查迁移条件、联合生成量的定义和区分实验，可能提高有限预算下的有效发现。

这是需要验证的假设。检索、条件检查、测量定义、主动实验分别已有先例；目前没有证据证明这一具体组合构成文献空白或性能优势。

第一轮先做六个开发案例，每类两个：

- 当前变量足够，只需改变 f 的形式；检验系统是否无故增加隐藏变量。
- 原始记录足够，但需要构造新的时间/对象表示；检验 agent 是否自行找到定义。
- 现有记录不足，必须补充测量或选择新实验；检验其数据请求能否解除可识别性问题。

每类尽量包含一个受控案例和一个有真实数据/明确历史研究链的案例。六例用于失败定位，不足以支撑总体优势。最终测试需要独立任务、重复运行和预先固定的评价标准。

比较：固定变量的 LLM-SR 类基线；MDA/BMD 类显式模型扩展；普通领域检索加模型搜索（应参考 OptScientist/IRIS 的变量构造做法）；拟议的差异定向检索与联合候选方案。明确完整复现与机制适配的区别。优化型问题可直接比较 OptScientist；其他问题不能把它放在接口不适配的任务上当作弱基线。

比较原则：相同底座模型、相同可见原始数据和工具权限、相同文献集合、相近总预算；分别记录模型 token、数值计算、检索与测量成本。方法比较与检索组件比较分开。不能靠多获得答案信息赢过基线，不开展 agent 人数消融。

主要评价：新条件下的事前预测、机制/变量识别（受控案例）、有效测量请求、无必要变量的引入率、总成本。使用共同原始观测或共同实验目标比较候选；变量名字、文本新颖度和训练集拟合不是主要终点。

检索专项对照可以固定候选材料，比较有用结构、主题相似但迁移条件不成立的材料和普通背景。先诊断检索是否找到材料，再诊断找到后是否转化为有效模型，避免把两种失败混在一起。设“研究者提供正确材料”的诊断上界，但不计作自主发现。

历史重发现需将可检索材料截在目标成果最早公开日期之前，包括预印本；这一措施控制检索泄漏，不能消除底座模型预训练中的答案知识。真实新发现另需独立实验和专项原创性检索。

推进判据：先观察强基线反复卡在哪一步；如果已有方法能够完成目标，复用它们并换一个有实际科学价值的任务。如果定向检索只让解释写得更好，没有改善候选可执行性和独立预测，就不扩展该组件。
