# 下一步：让失败决定下一项结构检查或干预

本轮结束，不再延长研究调用预算。先保留已验证的工具层，把agent科学选择的失败作为下一项设计依据。

1. **接口稳定性作为前置条件。** 用受约束构造操作绑定变量、参数和数量；单位/语法由程序处理。对于文字与公式的科学冲突返回澄清，不擅自把余弦改成衰减。有效初稿和无效初稿都保留。单纯修复这些问题不作为论文核心贡献。
2. **让新表示保留旧证据要求的区分。** 以实际提供给响应的特征检查碰撞，保持前提与撤回条件。没有碰撞只表示当前证据不能排除，不能自动把“可继续搜索”升级为“表示充分”。本轮已有工具可复用。
3. **增加一种有科学用途的实验工具。** 当前设计仅在最终选择后采集确认，无法在修订中取得能区分解释的新证据。下一版应允许agent在预算内提出并执行干预，再据结果修订。请求必须给出竞争解释、各自冻结预测及预期区分；自动拒绝重复条件，明确新条件与新的重复测量的差别。端点表示忽略中间历史，是本轮具体待检验缺口，不能直接预告给未来盲评任务。
4. **把语言提案与固定搜索目录比较。** 工具独立搜索已能解决本开发例子。LLM的增量价值要体现在选择有用的表示/实验、节省总计算或提出固定目录之外的可验证结构。与工具独立搜索用相同信息和完整计算账目比较。不能仅以成功公式或固定agent数量作为创新点。
5. **冻结接口和方法后更换机制。** 新机制、新组合与新观测映射不得再用于设计工具；保留不需新量、测量错误和不可识别情形，防止强加隐藏量。诊断任务与开放结构发现分开计分。先做小规模可识别性与运行可行性核查，再冻结正式预算。

检索与跨域结构迁移仍属于最终系统，但当前不能用增加角色来代替上述缺口。本文件是下一项设计建议，尚未启动新实验，也未建立文献新颖性。
