# 04 定向学习回报：从「符号结构」到「规范类」

## 1. 我请求的缺口与回报
请求：混合符号 / 非互易（Δα≠Δβ）hysteron 网络上 l-RPM 的判据，含三个子问题：(a) 「铁磁型保持 l-RPM」的证明是否覆盖含雪崩的网络；(b) 混合符号是否有可判的充分条件（例如标签重标定使各边同号）；(c) 只能受拉的钢丝边是否等价于非互易、落在定理之外。

回报：12 个源，全为 indexed abstract 或仅标题；检索词漂移到随机场 Ising、pinwheel 自旋冰、Preisach 工程应用与「hysteron proteron」修辞。**没有任何一个给出所请求的判据**，(a)(b)(c) 仍未由外部知识回答。

真正可用的三条：
- **PRE 102, 012122 (2020)**：无相互作用 Preisach 模型的转移图中，「很大一部分拓扑不由切换场数值、而由排列 ρ 支配」；ρ 是沿主回线元素换态的顺序；|R| = ρ 的递增子序列数。同文指出有相互作用正是 Preisach 描述失效之处。
- **RFIM on Bethe lattice (1997)**：磁化跳变的存在依赖配位数 z（z=3、高斯无序：任意非零无序强度都不出现跳变；弱无序下需更大 z 才有跳变）。
- **pinwheel ASI (2019)**：有效耦合包含由磁化末态诱导的赝交换，耦合系数不是纯几何常数；拓扑对称性降低还引出各向异性与角落介导的雪崩。
- 另有 **R-IR 综述 (2023)** 提供一个区分：周期驱动系统最终进入「可逆（轨迹逐周期重复）」或「混沌」，由振幅与循环数决定。

## 2. 概念动作：符号是标签，还是内容？
前提（threshold_coordinate_factorization）：耦合以等量平移进入，F_i^±(σ)=c_i+b_iσ±h_i。
若邻态求和线性可加，则对任意子格翻转 σ_i→−σ_i，所有与之相连的 b 变号，而「释放阈值作为 σ 的函数」只换变量名；沿主回线的释放排列 ρ 不变。
由 ρ 支配拓扑（摘要级已发表）⇒ 单符号（无论正负）与「回路符号乘积处处 +1」的有符号图同属一个记忆类别。
⇒ 只有两类东西不能被标签吸收：
(i) 奇数条反铁磁边的回路（挫折/不平衡）；
(ii) 无法写成 ±b 的边（单侧、状态依赖、非互易）。
两者判别量不同：回路奇偶是离散的符号乘积；非 ±b 是 Δα≠Δβ。
注：这条推导只用「拓扑由 ρ 支配」这一句，而它由已发表文献给出的是**无相互作用**情形；把它用于有相互作用网络是我的外推，不是已发表结论。

## 4. 条件性后果（若规范论证成立）
1. pair_A（b<0）与 pair_B（b>0）属于同一记忆类别；可观测差别只剩锁存/雪崩发生在哪个扫描方向。
2. 固定几何下增大 |b| 只能在「改变释放顺序（ρ 变）」的那一点上改变记忆结构，不会随 |b|/间隙 连续变坏。
3. network_C 若确为「链式最近邻交叉 + 一条 1–3 钢丝边」，则 1–2–3 回路的符号乘积决定不平衡与否；「有一条钢丝」本身不构成记忆风险。
4. 两转子装置没有回路，任何单边符号都可被吸收 ⇒ 这类装置原则上不能因符号而改 l-RPM。
5. 「混合符号＝脆弱」这一表述会被判为错：平衡的混合符号图与单符号图同属一类。
