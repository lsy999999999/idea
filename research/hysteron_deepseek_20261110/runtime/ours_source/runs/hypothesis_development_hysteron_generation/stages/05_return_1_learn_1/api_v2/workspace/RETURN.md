# 05_return_1_learn_1：把「已测阈值」接到「能量耦合」

## 0 上轮留下的具体缺口
上一轮只用线性响应就纠正了消去的符号（按能量 −ΣKσσ，稳定支消去给 K_eff=+K_ikK_kj/K_k，单中介树上诱导三角恒平衡），把 healing/manufacturing 判据改成「直接边与诱导边反号占优，或中介走负刚度支」。但这条判据无法落到任何现有表上：从没写出**已测的夹紧阈值**与**能量耦合 K** 的映射；同时 pair_A 两个转子的 |Δα| 相差 3.7 倍（1.2 与 4.4 cm），看上去与「能量耦合对称、K_12=K_21」的前提冲突。这两个问题都只用给定行就能检查，故本轮不靠新数据。

## 1 三通道分解（对给定 rows 的工作性计算，非新实验）
对每格取 c=(γ_up+γ_down)/2、h=(γ_up−γ_down)/2，把 other_state=+1 与 −1 相减得 b≡Δc、Δh：

| 装配 | 转子 | ℓ=4.7 cm 时 other−1 的 (c,h) | other+1 的 (c,h) | b=Δc | Δh |
|---|---|---|---|---|---|
| pair_A（并联，k_c=0.07） | 1 | (0.9, 4.6) | (−0.3, 4.6) | −1.2 | 0.0 |
| pair_A | 2 | (3.8, 1.1) | (−0.6, 1.1) | −4.4 | 0.0 |
| pair_B（交叉，k_c=0.19） | 1 | (2.6, 4.1) | (13.7, 4.0) | +11.1 | −0.1 |
| pair_B | 2 | (13.5, 11.4) | (19.0, 11.7) | +5.5 | +0.3 |

- 邻态依赖只动 c，不动 h（|Δh| ≤ 0.3 cm，全部接近读数分辨率 0.1–0.2 cm）。即邻态是一股**确定性场**，把环路整体平移；它不改变环路宽度。
- ℓ 序列（pair_A）：b_1 = 0 / −0.1 / −0.6 / −1.2；b_2 = 0 / −0.4 / −1.9 / −4.4（ℓ=0/1.577/3.154/4.731 cm）。
- 与此并行的是宽度通道：1−w/w0 = 0/0.056/0.167/0.361（转子1）与 0/0.059/0.176/0.353（转子2）——两转子止挡角差 3.7 倍，而收缩比例几乎相同（这一点与 peer 的 coupling_torque_moments 表一致，不是我的新观测）。

## 2 读数规则（条件性）
1. **符号**：sign(K) = −sign(b)，K>0 指并联/同向占据低能。pair_A b<0、pair_B b>0，与「并联 vs 交叉」一致。metric 为正，故符号乘积与受挫奇偶**保真**：奇偶原则上可由逐边夹紧格读出，不需装配图。
2. **幅度**：|b| 不是 K。四格拟合 |b| ≈ C·(k_c/k_d)·(ℓ²/L)·sinθ_邻居，C = 5.05 / 5.65 / 5.05 / 5.00（转子1/2 of pair_A、转子1/2 of pair_B），偏差 ±12%。比值检验更好：pair_A 3.67 对 sin 比 3.27–3.50；pair_B 2.02 对 2.00。
3. **竞争解释**：3.7 倍不对称也可能来自 x_mount_offsets（pair_A 0/−1.9）。但 pair_B 的偏移是 −8.1/−16.4、完全不同，其比值仍精确落在 sinθ 比上，故 sinθ 解释占优——这只是弱证据，不是判定。
4. **场与宽度的分离**：χ=|b|/(2h)。pair_A 转子1 0.13、转子2 2.0；pair_B 转子1 1.37、转子2 0.24。χ≳1 时，邻态翻转足以把固定 γ 下的工作点推过自身阈值，因此 ±1 事件串的先后次序承载信息——而导出约定明确「时间间隔未解」。

（以上第 1–4 条是我从给定 rows 与 peer 已算的 1−w 表推出的读法；机制层面（线性化弹簧力矩、被夹紧转子停在止挡角）未验证。）

## 3 这改了什么
- 受挫奇偶从「无法用现有表判定」改为「符号可测、幅度带 metric」：判据可作用，但 |b| 的跨转子/跨装配比较必须先去 metric。
- pair_A 的 3.7 倍不对称不再读成互易性破坏或单侧边证据；它给出一个设计后果：把邻居做成大止挡角，就能造出「影响大、受影响小」的**可见**非对称，而能量仍互易——这与已发表「用非对称能量景观编程非互易」是不同路线。
- 消去的两条输出通道被分开：刚度（态对称，改 h/κ）与场（态反对称，改 c）。上轮 parity 结论属场通道；「复合元失稳/截断」属刚度通道，二者可观测不同（Δα=Δβ≠0 vs Δh≠0）。
- χ 给 network_C 的并列事件一个更硬的诊断：在无夹紧格、无时间戳时，并列不可判不是懒惰，而是当 χ≳1 时事件图本身不唯一。
