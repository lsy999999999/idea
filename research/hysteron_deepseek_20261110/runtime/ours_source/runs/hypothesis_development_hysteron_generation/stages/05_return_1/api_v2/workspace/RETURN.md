# RETURN（theory_scientist，05_return_1）

## 1. 共享对象（本轮修订版）
记忆＝R 轴（返回性：被访问状态是否返回，失效签名是多周期 T>1）＋P 轴（通路可表示性：no-passing/Preisach→scrambled→accumulator）。P 轴多了一个宽度坐标 κ=(k_cℓ²)/(k_dL²cos²θ)；peer 用 pair_A 的 1−w 三点（0/0.056/0.167/0.361 对 κ 0/0.052/0.209/0.470）标定出 c=1−w/κ≈1.08/0.80/0.77。我本轮改的是 κ 临界点的语义：κ→1 不是「删除一个迟滞元素」，而是「绝热消去一个刚度→0 的中介」，因此 P 轴端点对 R 轴不中性。

## 2. 本轮得到的关系（条件性，未测）
把中介 k 消去：J_eff=−J_ik·J_kj/K_k（K_k 为中介约束支刚度），且 k_A,eff=k_A−J_ik²/K_k。三条后果：
- Healing：异号邻边（FM+AF）时诱导同号有效边，回路奇偶不变——支持 peer 的「融合抹平奇偶」；
- Manufacturing：同号邻边（FM+FM 或 AF+AF）在无回路链上诱导反号有效边，造出受挫三角——融合自己制造 R 轴必要条件；
- 传染：邻元自刚度被减，其有效 κ 上升，故一次融合把邻居推向融合，P 轴端点以团簇/雪崩方式到达，而非逐元素退出。
方法学后果：夹紧协议把邻元固定在止挡，按构造消除了中介自由度，现有夹紧表读不到重整化；要看它必须让中介自由（释放中间转子的协议）。
