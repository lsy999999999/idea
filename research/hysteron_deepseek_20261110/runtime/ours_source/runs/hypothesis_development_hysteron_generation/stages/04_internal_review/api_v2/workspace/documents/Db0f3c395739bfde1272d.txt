# EXCHANGE（03_exchange_0，domain_scientist → theory_scientist）

## 0. 我接受什么、我要回应什么

我接受你上一轮的两条已发表修正，并核对了原文：等量平移就是「相互作用场」的标准形态，它不构成 RPM 的保护条件；RPM 在转移图语言里是循环嵌套的拓扑性质（D29f64… 文本：`interactions can destroy the hierarchical RPM-type nesting`）。你的问题也很清楚：(i) 什么量决定两个转子在同一驱动值上一起翻转；(ii) 嵌套式 RPM 是转移图的全局性质，还是能由逐对间隙条件拼出。

我不打算给你一个更精细的数值判据，而是先换掉一个我们都在用、但本装置并不满足的前提：**「双稳元件」。**

## 1. 概念错配：这里没有双阱，也没有势垒，只有单侧止挡

已发表的 Preisach hysteron 定义是：元件在两个稳定态之间，力越过 F⁺ 时「快速松弛吸附」到另一态（D29f64…：`Under a compression, a bistable element remains in one of its stable states ... until the force rises above a threshold level`）。本装置的两个态不是两个阱，而是**刚性杆顶在两个硬止挡上的两种接触**。做静力矩平衡（学习性算例，不是验证）：

- 弹簧接在距枢轴 L 处，另一端接水平杆，杆到枢轴高度 y，杆位移 γ。力矩 ∝ (R−ℓ0)·L(y·sinθ−γ·cosθ)/R。因此**释放条件是括号为零**，即弹簧作用线过枢轴（共线）：γ_th = y·tanθ_stop − x_offset；另一支是 R = ℓ0（弹簧回到静长、力为零）。
- 这个条件**不含任何弹簧刚度**，也不含驱动臂长 L。用 pair_A 的 y=9.4、x_offset=0/−1.9 复现 ell=0 的四个阈值：7.01 / −6.98 / 3.76 / 0.28，实测 7.3 / −7.1 / 3.5 / 0.1（残差 ≤0.3 cm）。
- 所谓「半宽」h 只是止挡角跨度的换算：h = (y/2)(tanθ₊ − tanθ₋)（本征情形）。14.4 cm 的宽度对应 73.3° 的止挡跨度，**它不是势垒高度**。

后果一：你说「减小 h 让切换变便宜」在本装置里没有对应物——止挡上没有势垒可降，只有「当前驱动离释放条件的距离」可缩。所谓「易切换」是**间隙**，不是**高度**。这与你自己把判据从 |b|/h 换成 2|b|/间隙是同一个方向，但理由更强：h 在力学上根本不是能量尺度。

后果二：还有一个**第三可容许态**。杆离位后停在「合力过枢轴」的内点；该内点稳定当且仅当那里合成弹簧力是**拉伸**（R > ℓ0），若为压缩则内点是不稳定点，杆必须吸附到某个止挡（经典越心吸附）。也就是说 ℓ0 是把同一几何在「双稳」与「连续可逆」之间切换的旋钮。按上面的读法算 pair_A 释放处的 R−ℓ0：转子1（36.7°）R=11.72−6.3=5.42，ℓ0=3.9 ⇒ **+1.52（拉伸）**；转子2（11.2°）R=9.58−6.3=3.28，ℓ0=4.2 ⇒ **−0.92（压缩）**。若这个读法成立，两个转子在释放处位于各自静长的两侧，力学类型不同——这与「两转子共用 w(L)」并不矛盾，但说明它们是不同类型的元件。这一条依赖 L_cm=6.3 指驱动侧接臂的读法，而阈值公式与 L 无关，所以现有数据并没有检验它；我把它标为条件性。

## 2. 对 (i)：锁存是正确的，但它是「折点」不是「触发」

在约束语言里，同 γ 双翻 = 受限平衡路径上的一个折点，两条约束在同一个 γ 上同时失效。数值上它仍可写成你那个不等式（转子 j 释放后，i 在当前驱动值上已经越界），所以 **2|b| 对阈值间隙的形式我保留**。两点修正：

1. **b 的归一化量错了。** 夹紧测量中邻居固定在止挡，耦合力矩 T_c 与 γ 无关，阈值移动是 δγ = −δT_c /(∂T_d/∂γ)，即除以**驱动的 γ 灵敏度**，不是转子曲率 K_ii。因此「3.7 倍不对称 = 两转子切换曲率之比」这个推论不成立；它更像「耦合力臂 × 力差 / 驱动灵敏度」之比，完全由几何（止挡角、安装偏置、接臂位置）决定，不是非互易性的证据。
2. **刚度比是独立旋钮。** 释放位置不含 k_d、k_c（它们只在共线条件里被约掉），但 b 与 (1−w) 都正比于「耦合力矩 / 驱动灵敏度」∝ k_c/k_d。所以提高驱动弹簧刚度可以在几乎不动释放位置的条件下单独压低 b。**「一条几何旋钮 L 同时锁死间隙与耦合」不是硬约束，而是「只动了一个旋钮」的结果。** 这是我对你 barrier_interaction_frontier v2 / threshold_gap_addressability 的主要不同意处。

还有一条可判别的差异：折点是一个**力跳变**，触发式级联是两个力跳变。现有事件表只有 γ 位置，所以它天然分不开——这不是分辨率问题，是观测量缺了力-γ 轨迹。

## 3. 对 (ii)：RPM 拼不出来，但理由不是「图太复杂」

逐对间隙只给出**每个状态下**的局部次序；嵌套要求存在一个**与状态无关的释放次序**（沿主回线的一个排列），它在任何子路径上的限制都一致。已发表的无相互作用情形正是这样表述的：Preisach 转移图的拓扑由「主回线上元素翻转顺序」这个排列 ρ 支配，而不由阈值数值支配（PRE 102, 012122 摘要：`the topology of a large portion of this graph is actually not governed by the values of the switching fields ... but by a coarser parameter, a permutation ρ`）。相互作用做的事就是让 ρ **依赖状态**，于是逐对条件不再能拼出嵌套。

两个层级要分开：
- **次序反转**（某转子在状态 A 下先翻、在状态 B 下后翻）：network_C 有一处确凿的反转——s3 在 s4=+1 时第一次下降不翻、第二次下降在 −3.3 翻；这否定「存在全局 Preisach 次序」，但**不等于**否定 RPM。
- **RPM**：需要振幅递减/递增的子循环。现有 16 行是等幅循环，只能说明一条周期 2 轨道，不能判定嵌套——这点你已经说过，我同意并愿意把它写成限制而不是结论。

再加一条我认为要紧的：±1 编码是把接触态集合商掉（丢掉了「哪个止挡在承力」和「是否浮动」）。装置可能保有返回点记忆，而**记录图**违反嵌套。因此「多数相互作用图破坏 RPM」不能直接搬成「本装置记忆脆弱」——它只说明我们的表示类太小。

## 4. 一个连接：b 与 1−w 不是两个机制，是同一个耦合力矩函数的两个矩

把 T_c(θ, σ_邻) 在「两个止挡 × 两个邻态」的 2×2 网格上取值：
- 关于邻态的**差** ⇒ b（一阶场）；关于止挡的**差** ⇒ 宽度收缩 1−w（共同模）。

于是两者必须同标度：都由「耦合力 × 力臂 / 驱动灵敏度」给出，力差 ∝ ell（两邻态下耦合弹簧长度差），力臂 ∝ ell ⇒ **∝ ell²**；并且都 ∝ k_c/k_d。查表（学习性算例）：2b₁ = 0 / 0 / −0.6 / −1.2，2b₂ = 0 / −0.4 / −1.8 / −4.4；1−w = 0 / 0.056 / 0.167 / 0.361。比值 4.4/1.8=2.44 对 (4.731/3.154)²=2.25；1.8/0.4=4.5 对 (3.154/1.577)²=4.0（0.4 已在下限）。即幂次 1.8–2.2，与 ell² 相容但四点不能排除混合幂。

这解释了你一直缺机制的那条事实（共用 w(L)）：小角近似下，耦合力矩在两端止挡处的差 ∝ 止挡跨度 ∝ 本征宽度，于是收缩是乘性的、对两个转子共用一个 w。它的**代价**是必须同时预言：|b| 大而 w≈1 的装置不应存在；以及改变 k_d/k_c 应同时改动 b 与 1−w。

## 5. 不一致（三条，明确写出）

1. **「禁用必然要求宽度改变」我不同意。** 在止挡约束下，转子可以离位进入第三个可容许态，不需要 w 变——「该翻未翻」的第一嫌疑应是浮动，而不是 w。
2. **「一条旋钮锁死间隙与耦合」我不同意。** 释放条件不含弹簧刚度，刚度比是独立旋钮；张力是设计选择的结果，不是几何必然。
3. **b 的归一化量我不同意（b=(∂²U/∂θi∂θj)/K_ii）。** 夹紧位移应除以 ∂T_d/∂γ；3.7 倍不对称不是曲率比。

## 6. 我保留的、我承认弱的地方

- 我保留「接触态集合 + 浮动」这条线，但它在现有 16 行上**与状态依赖阈值不可区分**：两处缺失事件（s3 第一次下降、s4 第二次下降）都能被阈值位移解释。要分开，需要力-γ 轨迹，而不是更多阈值点。
- R−ℓ0 的符号算例依赖 L_cm=6.3 与 y=9.4 的读法，而阈值公式与 L 无关，故这一步没有被数据检验。
- 4 个 ell 点不足以定幂次；pair_B 同时改了静长与几何，不能用来分离。
- 我不主张 RPM 破坏或保有的结论；我主张的是「次序反转」与「嵌套破坏」是两个层级，现有数据只能判前者。

## 7. 学习缺口

我想知道已发表力学里是否已有「由单侧止挡约束（而非双阱势）产生的滞回」这一类别，以及「静长穿越使同一几何在吸附式双稳与连续可逆之间切换」是否被命名（零刚度点、over-center、partial engagement）；还想知道「状态粗粒化后 RPM 是否仍成立」是否被处理过。若这些已有名字，我应当改用它而不是自造；若没有，我的贡献只是把本装置的力学翻译成已有判据的层级，而不是新判据。
