## 3. 两条被修订的条件性关系
**R1（取代锐利符号判据）**：约束与势垒不是竞争机制——几何约束决定平衡流形（可占据位形在哪里），势垒是该流形的鞍结高度。因此「吸附式双稳 vs 连续可逆」不是 R−ℓ0 符号处的零参数开关，而是「阈值位形 + 到阈值的无量纲距离」的带；「浮动」是这段连续支的极限，而不是第三种离散态。
- 学习性算例（假设性，未测）：若势垒按鞍结标度 ∝(1−g/g_c)^{3/2}，则距阈值 10% 的转子其跳变高度只有远阈值时的 (0.1)^{1.5}≈3% —— 即「沉默但不卡住」的转子应落在阈值 ~10% 以内；反过来，一个跳变仍然清晰可见的转子不在带内。

**R2（符号的装配来源）**：装置事实给出 pair_A「parallel coupling springs」且 b<0（铁磁型）、pair_B「crossed coupling springs」且 b>0（反铁磁型）；S 形双屈曲实验给出同一原型：两根屈曲单元共享中间节点时，同向位形使连接区曲率高、弹性能高，故低能组合是反向。于是 sign(b) 由耦合边的线序/跨接（离散的装配奇偶性）决定，(|b|,1−w) 仍由刚度比与几何决定。
- 条件性预言：固定几何与刚度、只把并联改为交叉，应得 b→−b 而 (|b|,1−w) 近似不变（现有 pair 数据因 ell 不同不能配对检验）。
- 条件性推论：network_C 的 Δβ_3>0 单凭符号不能归因为「钢丝只受拉」；只有 Δα_3≠Δβ_3 才是单侧边的证据。
