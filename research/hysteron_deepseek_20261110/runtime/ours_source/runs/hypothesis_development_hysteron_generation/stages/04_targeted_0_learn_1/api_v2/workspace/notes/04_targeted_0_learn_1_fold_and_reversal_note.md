## 2 学习一：极限点判据是「总有效刚度为零」，几何只是它的 k_d→0 极限

已发表（Kfcfbb077 正文）：失稳处最低阶基频降到零；失稳前整体有效刚度增加、失稳后下降；「snap-through 行为可以有也可以没有，而 pull-in 总是存在」；阈值随中点初始拱高升高、随有效长度降低。已发表（K233c25 摘要）：存在一个最小无量纲刚度 β 决定能否 snap。

我的推断（不是已发表结论）：把「到阈值的距离」换成「两个刚度的比较」。

- 位置判据：T_d(γ,θ)+T_c(θ,σ)=0，与 k_d 无关 ⇒ 换驱动弹簧不移动释放 γ。
- 可见性/存在判据：∂²U/∂θ² = K_ctrl − |K_neg|，K_ctrl = k_d L²cos²θ。定义 Ω = K_ctrl/|K_neg|：Ω>1 无跳变；Ω 从上方趋于 1 时跳变趋于 0；Ω<1 才有跳变。
- k_d→0（死载）时 Ω→0，退回纯几何存在判据（rise/length、x_offset、R−ℓ0）。所以几何判据不是竞争解释，而是极限情形。

反例压力（K1f367e2 正文）：大长宽比薄板的临界剪切位移是纯几何、与厚度无关、无拟合参数。这限制了 Ω 的适用域：它属于「有限控制刚度、且负刚度与之可比」的弹簧-止挡装置，不是普遍力学真理。

## 3 学习二：记忆对象是反转点序列，不是状态字母表

已发表（K1364a25 摘要）：play/stop/Preisach 可写成连续分布函数；共有同余与擦除性质；历史由过去反转点序列描述；stop 是 play 的倒置。已发表（Kd215cb 摘要）：主回线图拓扑大部分不由切换场数值、而由一个更粗的排列 ρ 支配，|R| 等于 ρ 中递增子序列数。

我的推断：±1 只是输出字母表。RPM 应写成「被保留反转值的后进先出/擦除」结构：连续幅度本身不破坏 rpm（play 算子就是连续输出的），破坏源是支切换不完整或单侧边（peer 的 Δα≠Δβ）。若某转子停在连续支中间，序列里会留下一个没有事件对应的反转值，±1 表会显得破坏次序。

## 4 学习性算例（明确标注：假设性、数量级，不是对数据的拟合）

输入取自 apparatus/threshold 表：pair_A，k_d=0.19 N/cm，L=6.3 cm，k_c=0.07 N/cm，耦合安装距离 r=4.731 cm，取 θ≈20°。

- dT_d/dγ = k_d L cosθ ≈ 0.19×6.3×0.94 ≈ 1.1 N·cm 每 cm 的 γ。
- 观测移位 2|b_1|=1.2 cm（L=4.731，转子1）⇒ ΔT ≈ 1.3 N·cm。
- 耦合弹簧可给的同量级力矩：2×k_c×(rΔθ)×r，取 Δθ=0.6 rad ≈ 2×0.07×2.8×3.8 ≈ 1.5 N·cm。⇒ 与 1.3 同量级，b 的读法自洽。
- 转动刚度：K_ctrl ≈ 0.19×39.7×0.88 ≈ 6.6 N·cm/rad；K_coup ≈ 2×0.07×22.4 ≈ 3.1 N·cm/rad；Ω ≈ 2.1。
- 含义（条件性）：若负刚度只来自耦合弹簧，驱动会压住跳变；那么已记录的同 γ 双翻只能由驱动-止挡几何的负刚度提供，或本算例的小角/力臂假设在 36.6° 止挡处失效。两条都可用现有夹紧协议部分读出，但现有表不能区分。
- 注意：标定样 S046/S007（0.46/0.07 N/cm）只是标定样品，brief 明确它们不必然是机上弹簧的身份，因此「换驱动弹簧」是装置可能性，不是已知事实。
