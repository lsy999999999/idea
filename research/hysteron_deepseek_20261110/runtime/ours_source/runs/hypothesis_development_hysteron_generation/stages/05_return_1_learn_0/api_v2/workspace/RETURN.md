## 2. 焦点
上一轮写：J_eff = −J_ik J_kj / K_k，并据此说同号邻边诱导反号有效边、造受挫三角。这里没有检查 J 是能量交换耦合，还是刚度矩阵非对角元。

## 3. 符号检查
固定能量约定 E = −Σ K_ij σ_i σ_j，K>0 为铁磁型。三节点 i–k–j，k 的约束刚度为 K_k。线性响应下消去 x_k：
x_k = (K_ik σ_i + K_kj σ_j)/K_k，
E_eff = −(K_ik σ_i + K_kj σ_j)^2/(2K_k)
= −(K_ik^2+K_kj^2)/(2K_k) − (K_ik K_kj/K_k) σ_i σ_j。
所以
K_eff = +K_ik K_kj / K_k，
K_i,eff = K_i − K_ik^2/K_k，K_j,eff = K_j − K_kj^2/K_k。
若把刚度矩阵非对角元记为 S_ij = −K_ij，则 S_eff = −K_eff = −S_ik S_kj/K_k。上一版的 −J_ikJ_kj/K 对应的是 S，不是 K；把 S 的符号直接读成 FM/AF 就多了一个负号。

## 4. 树与回路
在 i–k–j 链上，消去 k 后新增边 i–j。三角 i–k–j–i 的交换耦合乘积：
K_ik · K_kj · K_eff = (K_ik K_kj)^2/K_k > 0。
所以它总是平衡的，不能由「同号邻边」制造受挫三角。更一般地，若 k 在回路中，i 与 j 之间没有直接边，则
K_eff · P = (K_ik K_kj/K_k) · P
与原回路乘积 K_ik K_kj P 同号：稳定消去保持受挫奇偶，不单独 healing 或 manufacturing。

只有两种情形能翻转奇偶：
1. i 与 j 之间已有直接边 K_ij，新边为 K_ij + K_eff；两者反号且 |K_eff| > |K_ij| 时，新边符号翻转。
2. 中介在负刚度支 K_k < 0；此时 K_eff 翻号，但该支不是稳定平衡，绝热消去失效。应把中介保留为隐藏慢变量，而不是写成一条稳定有效边。

## 5. 与 peer 的分歧
peer `degeneracy_heals_frustration`：退化单元只是对邻居的确定性场，只移阈值、不储历史，故不单独产生多周期。
- 同意「不储历史」和「稳定支上不单独产生多周期」。
- 不同意「只移阈值」：消去它会在邻元间留下有效耦合，改变联合能量；即使无历史，也会改变回路符号乘积的幅度，并在有直接边时改变符号。
- 因此「κ 跨 1 抹平受挫奇偶」在树上平凡真（本来无挫折），在回路上不成立（无直接边时奇偶保持）；只有直接边竞争或负刚度支才可能改变。

peer `unilateral_stop_state`：κ→1 时单元退化为 γ 的单值单调函数，环路关闭。
- 同意单元局部环路关闭。
- 不同意把它读成网络回路被删除：单元局部单值化后仍可作为约束在中介两侧留下有效边；网络级周期/嵌套要单独读。

## 7. 学习性算例（假设，未测）
取 K_ik=1, K_kj=−1, K_k=2（任意单位）。K_eff=(1·−1)/2=−0.5。三角乘积 = 1·(−1)·(−0.5)=+0.5，平衡。
若再加直接边 K_ij=+2，新边 = 2−0.5=1.5；三角乘积 = 1·(−1)·1.5=−1.5，受挫。
所以决定奇偶的是直接边与诱导边的竞争，不是「两条邻边是否同号」。
