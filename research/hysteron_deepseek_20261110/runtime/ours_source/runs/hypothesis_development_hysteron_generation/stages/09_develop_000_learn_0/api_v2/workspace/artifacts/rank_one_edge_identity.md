# 单簧边的 Hessian：秩一、符号奇偶与振幅上限（学习算例，非实验结论）

本文件是 domain_scientist 在 09_develop_000_learn_0 的推导记录。数据全部来自 measurements_brief.json 的 40 个 threshold 行（record_id 68–107），未使用任何未公开材料。

## 0. 三句话结论

1. 上一轮的核心定量事实——『宽度通道 ℓ 幂 1.63、场通道 2.22』——在 ±0.1 cm 驱动分辨率内不存在：两列都与 ℓ² 相容。
2. 存在一个无自由参数的恒等式 b1·b2 = 4·Δh1·Δh2（Δh 为相对 ℓ=0 的环宽收缩），实测 0.95（ℓ=3.154）、0.85（ℓ=4.731）；它是『单簧边 Hessian 秩一』的直接推论。
3. 预压 ε 进的是同一个因子 B，不能使对角与非对角异号；b 的符号只由两耦合臂切向的平行/反平行决定（s=sign(τ1·τ2)）。于是 pair_A 的 b<0 要求两臂异侧——这是一个可被案件几何否掉的预言。

## 2. 推导

设单根线性弹簧接在两转子力臂端（切向 t_i=ℓ_iτ_i，弹簧轴单位向量 r̂，R=|r|，ε=R−ℓ0，k_c 为其刚度）。

a_i=∂R/∂θ_i = −(r̂·t_i)，∂_i∂_jR = −[t_i·t_j−(r̂·t_i)(r̂·t_j)]/R，代入 U=½k_c(R−ℓ0)² 得

  S_ij = k_c[ (r̂·t_i)(r̂·t_j)(1+ε/R) − (ε/R)(t_i·t_j) ]。

若两力臂切向共线（τ2=±τ1，cosψ=r̂·τ，s=sign(τ1·τ2)）：

  S_ij = s · B · k_c ℓ_i ℓ_j ,  B = cos²ψ(1+ε/R) − ε/R ,

对角与非对角拿到同一个 B。B 的性质：

- 稳定性（两态、环宽为正）要求 B>0 ⇔ ε < R·cot²ψ。
- B≤1 恒成立，等号当且仅当 ψ=0（力臂垂直于弹簧轴，即力矩臂最大、切向与弹簧轴平行）；此时 B=1 与 ε 完全无关。
- 于是 ε 只能整体缩放该边，不能把宽度通道与场通道推向相反方向。

由 h_i 与 b_i 的定义，b_i ∝ 2S_ijθ_j/(k_dL)、Δh_i ∝ S_iiθ_i/(k_dL)（同一驱动几何因子），秩一即给出

  b1·b2 = 4·Δh1·Δh2  （θ、k_c、k_d、ε 全消去），  以及  b1/b2 = θ2/θ1。

## 3. 哪些旧命题作废、哪些被替代

- 作废（我上轮自己的）：『预压项在 ∂_i∂_jR 与 ∂_i²R 上异号，因此宽度与场反向移动，可作判读』。代数上二者是同一 B 的两个位置，任何 ε 都同向缩放；且该判读所依赖的幂差本身在分辨率内不存在。
- 作废：『平移列幂 2.22 比宽度更陡，所以 κ 只统宽度』。
- 替代：秩一 ⇒ 两列是同一因子 B 的两个权重（θ_i 与 θ_j）；『通道可分』= 边 Hessian 秩≥2，即同一对转子上要有两簧且切向奇偶相反（或切向不共线）。
- 保留并加强：单簧边无非可规范符号，因此单簧网络无挫折；符号 s 是几何奇偶，不是材料属性。

## 4. 振幅（条件性）

λ = N·B·k_cℓ²/(k_dL)。取 N=2、k_c=名义（pair_A 0.07、pair_B 0.19）、k_d=0.19 N/cm、L=6.3 cm：

- pair_A（ℓ=4.731，λ≈3.36）：B_obs=1.28
- pair_B（ℓ=4.7，λ≈8.40）：B_obs=1.20

两台独立装置给出同一个数 ≈1.2，且都在单簧几何上限 B≤1 之上 20–30%。唯一自然的吸收项是『装机弹簧刚度 ≈1.2–1.3× 标定样本名义值』——这正是 data_dictionary 已写明的保留（标定样本不是每根装机弹簧的身份）。若 N=1，则 pair_A 需 B=2.57（几何上不可能），除非 mount_l 不是力矩臂。故数据在 N=2 的读法下自洽；N 本身仍是反推量，不是案件事实。

## 5. 局限

- 手算复算（analyze_csv 不支持行切片，未能用工具复核）；未做误差传播。
- 假设 Δh 与 b 的驱动几何因子相同（同一 k_dL 与同一线性化）。
- mount_l 是否即各转子自己的力矩臂、两转子臂长是否相等：unknown；宽度比 4.33 对 θ 比 3.49 差 24%，若臂长相等则是一处未解释残差（等价于 ℓ1/ℓ2≈1.11）。
- ψ 只能由振幅反推，耦合安装点坐标不在表内。
- 秩一/可规范在文献中的地位：本轮检索全失败，仍 unknown。
