# MATERIALS：机械滞后单元（hysteron）案例的材料与开放情境

## 0 情境与边界

- 数据：`measurements.csv`，123 行 = 67 行标定 + 40 行阈值 + 16 行状态事件。三台装置 pair_A（并联耦合、双转子）、pair_B（交叉耦合、双转子）、network_C（四转子网络）参数不同，**不可共享拟合参数**（数据字典明确说明）。
- 每行是 figure-source 记录，不是独立重复制备：无重复、无误差棒；两转子阈值不确定度 ±0.1 cm；事件表无时间戳、无反转行。
- 历史边界 2024-09-12。本文所用三个公开来源均早于边界；隐藏的原始研究及其解释不可读、未使用。
- 明确禁止的推断：由事件极值推断驱动反转位置；把 `event_index` 当作时间；假定标定样件就是装机弹簧。

| 编号 | 条件/假设 | 影响 |

## 2 材料条目（可追问的观察情境）

### M1 弹簧标定的线性与小回线
**观察**：三个名义弹簧在约 0.06–0.33 m 区间内 F 对 x 近似线性；同一 x 在加载/卸载支上相差不足约 1%（S046，x=0.20591 m：7.66504 N 对 7.60226 N）。对含两支的全部标定点做最小二乘（**学习性计算**）得 45.85、18.97、6.96 N/m，与名义 0.46/0.19/0.07 N/cm（46/19/7 N/m）相差 <1%。
**条件**：静态拉伸，已知质量置于电子天平；每个弹簧 13–29 个点，含一次加/卸载往返；无重复、无误差棒；标定样件未必是装机件。
**期望**：F ≈ k(x−x0)，k 接近名义值；两支近重合；若存在小回线，应可归因于弹簧内摩擦、接头摩擦或天平读数滞后，而不是率相关滞后。
**期望依据**：线性弹簧（Hooke 定律）是装置分析的基本理想化；名义刚度标签给出独立预期；准静态加载使率相关项可忽略。
**已有解释**：线圈弹簧的线性弹性；工程文献中静态循环加载下弹簧-阻尼组合体确实呈现回线（未纳入本次来源清单）。
**未解歧义**：装机弹簧的真实 k 与自由长度；x0 是否随安装预压改变；约 0.5% 的回线是真实耗散还是读数噪声（未给分辨率）。
**来源**：无（教科书级理想化；未检索到可引的公开来源）。

### M2 单转子阈值的 up/down 不对称
**观察**：pair_A，另一转子固定于停位。转子 1（L=0）：up=+7.3、down=−7.1 cm（other=−1 与 +1 完全相同）；转子 2（L=0）：up=+3.5、down=+0.1 cm（两种 other_state 也相同）——几乎“单向”。L=0 时耦合弹簧接在支点，故 other_state 不影响阈值，这一致性本身就是一个可检验的结构事实。
**条件**：另一转子夹在 −1 或 +1 硬停位；准静态往返；±0.1 cm。
**期望**：若单元在 θ→−θ 下对称，up/down 阈值应等大反号；观测到的偏置意味着景观被倾斜（重力矩、弹簧自由长度/预压、安装偏移 x_mount_offsets=[0,−1.9]、停位不对称 ±36.6°/36.7° 与 ±9.8°/11.2°），等效于上下阈值 α≠|β| 的 hysteron。
**期望依据**：对称双阱的逃逸势垒相等；Preisach/play 算子允许一般阈值对 (α,β)（SRC-PREISACH-2023）；不对称能量景观的耦合双稳阵列支持单向转变波（SRC-NONRECIP-2021）。
**未解歧义**：偏置的主要来源；转子 2 的 down=+0.1 cm 是否已接近无势垒/单稳；阈值是否随驱动速率变化（未测）。
**来源**：SRC-PREISACH-2023、SRC-NONRECIP-2021。

### M3 耦合安装距离 L 扫描（pair_A）
**观察**（L = 0, 1.577, 3.154, 4.731 cm；其余几何固定）：

| 转子/方向 | other=−1 | other=+1 |
|---|---|---|
| 转子1 up | 7.3, 7.1, 6.5, 5.5 | 7.3, 7.1, 5.9, 4.3 |
| 转子1 down | −7.1, −6.5, −5.5, −3.7 | −7.1, −6.7, −6.1, −4.9 |
| 转子2 up | 3.5, 3.5, 3.9, 4.9 | 3.5, 3.1, 2.1, 0.5 |
| 转子2 down | 0.1, 0.3, 1.1, 2.7 | 0.1, −0.1, −0.9, −1.7 |

转子 2 的阈值移动随 other_state 变号（other=−1 时随 L 增大，other=+1 时随 L 减小），符合“耦合力矩方向随状态反转”；**转子 1 在两种 other_state 下都下降，只是幅度不同**，不符合这一朴素期望。
**条件**：并联耦合弹簧 k=0.07 N/cm，静长 2.4/2.6 cm；每点单次测量；±0.1 cm。
**期望**：耦合弹簧力矩约 ∝ k_c·L·f(θ,Δ)，随 L 增大；other_state 反转应使力矩反号，因而阈值移动量变号。
**期望依据**：弹簧力 × 力臂的可加几何（A2）；耦合刚度是传播/能垒的决定因素（SRC-MECHCOMP-2024）；相互作用可作为阈值偏移进入 hysteron 描述（SRC-PREISACH-2023）。
**未解歧义**：转子 1 为何不随 other_state 变号（两侧力臂不等？x_mount_offsets=[0,−1.9] 的非对称？停位限位？）；L=0 是否确实对应零力臂；L 只有 4 个取值且单次测量。
**来源**：SRC-MECHCOMP-2024、SRC-PREISACH-2023。

### M4 并联 vs 交叉耦合拓扑（pair_A vs pair_B）
**观察**：pair_B（交叉耦合，全部弹簧 k=0.19 N/cm，L=4.7 cm）阈值远大于 pair_A 同 L：转子 2 up = 24.9（other=−1）/30.7（other=+1），down = 2.1/7.3；pair_A 转子 2 对应为 4.9/0.5 与 2.7/−1.7。符号效应也反向：pair_B 中 other=+1 使 up 阈值更大，pair_A 中更小。更值得注意的是 pair_B 的“down”阈值可为正（转子 1 other=+1：+9.7 cm；转子 2 other=+1：+7.3 cm）——切换点连符号都不再符合“向 − 方向”的直觉。
**条件**：两套不同装置（不可共享参数）；pair_B 安装偏移 [−8.1,−16.4] cm、停位 ±18.3°/±38.8°、静长 4.1 cm；pair_B 仅一个 L 值，每格单次测量。
**期望**：更硬耦合弹簧 + 交叉几何会放大阈值移动并可能改变符号；但 30.7 cm 是否在驱动行程内、正号的 down 阈值是否源于强偏置，均未知。
**期望依据**：弹簧刚度 k 决定传播/能垒行为（SRC-MECHCOMP-2024）；交叉几何改变力臂与力的方向；对称/不对称景观可独立编程出非互易与可逆行为（SRC-NONRECIP-2021）。
**未解歧义**：交叉几何的精确连接方式；“down 阈值为正”是装置偏置还是记录约定；刚度、几何、停位范围三者在两装置间同时变化，无法分离。
**来源**：SRC-MECHCOMP-2024、SRC-NONRECIP-2021。

### M5 四转子网络的事件序列
**观察**：network_C 的 16 个有序事件恰为两遍相同的 8 事件循环：-+-+ → ++-+ → ++++ → +++- → -++- → --+- → --++ → ---+ → （回到）-+-+。计算核实：15 个相邻转移中 |Δs1|+|Δs2|+|Δs3|+|Δs4| 恒为 2（min=max=2），即**每个事件只翻转一个转子**。同一循环的驱动位置逐字重复（4.5, 5.8, 5.8, −4.3, −5.1, −5.1, 5.9, −3.3），其中 5.8 与 −5.1 各出现两次且顺序保留。
**条件**：四转子、恒幅循环驱动、按观察顺序记录；导出表无反转行、无时间戳；某些耦合安装距离不等，1–3 之间一对弹簧用钢丝延长；完整连接与停位角未给出；装置经迭代调节，非随机抽样。
**期望**：若各单元近似独立且无重排/磨损（Preisach 叠加），循环驱动应在同一驱动值回到同一状态（return-point memory），中间状态次序由阈值集合决定；弱耦合相对阈值分散应给出逐个单翻转的“阶梯”，强耦合则可能出现雪崩/集体翻转。
**期望依据**：Preisach 类叠加及 congruency、wiping-out 性质（SRC-PREISACH-2023）；耦合双稳网络中级联与传播的能量阻抗图像（SRC-MECHCOMP-2024）。
**未解歧义**：8 事件是否在单次半程内完成（反转点未知，禁止由极值推断）；5.8 与 −5.1 处的成对事件是否近同时；是否存在漏记的中间态；逐字重复是否等价于零耗散/无棘轮。
**来源**：SRC-PREISACH-2023、SRC-MECHCOMP-2024。

### M6 夹紧阈值能否预测自由网络
**观察**：40 条 threshold 行只给出 pair_A/pair_B 在另一转子被夹紧时的单转子阈值；network_C 有 16 条事件却没有对应的单转子阈值表。
**条件**：阈值测量要求另一转子固定于停位；网络测量中另一转子自由。
**期望**：若单元间相互作用只表现为阈值偏移、且无雪崩，单元素阈值表原则上可预测网络事件次序；夹紧阈值只是自由情形的近似。
**期望依据**：Preisach 型叠加假设单元相对独立（SRC-PREISACH-2023）；耦合触发与阻抗累积会改写有效能垒（SRC-MECHCOMP-2024）。
**未解歧义**：夹紧与自由情形阈值差多大；network_C 的真实连通性；是否出现同一状态在不同驱动值重现的路径依赖。
**来源**：SRC-PREISACH-2023、SRC-MECHCOMP-2024。

## 3 理论的成功范围（已发表内容 + 明确标注的推断）

- 已发表（SRC-PREISACH-2023 摘要）：hysteron 是“简单滞后算子”；Preisach 与 play 模型是这类算子的离散求和/连续积分形式；两者共享 congruency 与 wiping-out 性质，历史依赖可由过去反转点序列描述；模型是唯象/数学工具，对成核主导的滞后描述较差；play、stop、KP-hysteron 可视为 Preisach 类子类。
- 已发表（SRC-MECHCOMP-2024 正文节选）：由线性弹簧串联的屈曲双稳单元链中，传播由输入能垒 U_b 与输出透射能 U_out 的竞争决定（实测 ≈0.47 mJ 对 ≈0.73 mJ）；孤子宽度 N_soliton≈2–3；**弹簧刚度 k 是决定传播行为的唯一参数**；级联逻辑的能量阻抗会累积，N_cas < N_soliton 时传播被抑制。
- **推断（非来源原话）**：把上述“能垒竞争”迁移到转子-弹簧装置，意味着耦合刚度与几何（L、交叉/并联）应主要通过改变有效能垒来移动阈值，而不是改变阈值移动的方向——这与 M3 中转子 1 的异常形成张力。
- **推断（非来源原话）**：Preisach 叠加要求单元不相互作用；一旦耦合在翻转时互相推动，congruency 与 wiping-out 可能失效。这是本案例“单阈值表 → 网络预测”最脆弱的一环，但数据本身尚未检验它。

## 4 学习示例（仅用于理解概念，不作验证）

## 6 未解歧义与共同提问清单

1. pair_A 转子 1 的阈值随 L 下降为何不随 other_state 变号？是几何非对称（安装偏移）还是另有偏置源？
2. pair_B 的“down”阈值为何可以为正？是强偏置、交叉几何，还是“up/down”标签只表示驱动方向而非阈值符号？
3. network_C 的 8 事件循环是否在单一往复内完成？反转点数据缺失，任何由事件极值反推的做法都被协议禁止。
4. 夹紧条件下的单元素阈值，能在多大程度上预测自由耦合网络的事件次序？需要什么最小附加信息（连通性？停位角？自由转子阈值）？
5. 循环逐字重复是否意味着无耗散与无棘轮？还是仅仅说明测量分辨率下不可分辨？
6. 若把“能垒竞争/阻抗累积”图像（SRC-MECHCOMP-2024）搬到转子装置，它预测什么可观察量（例如阈值随 L 的曲率、循环中的事件间距），与现有数据哪里冲突？
