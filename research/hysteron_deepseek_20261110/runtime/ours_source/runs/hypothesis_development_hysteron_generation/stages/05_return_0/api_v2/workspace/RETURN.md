# domain_scientist 返回（05_return）

## 1. 本轮共同对象的变化
上轮我的可见性判据是 Ω=k_dL²cos²θ/|K_neg|，问题是 |K_neg| 无法由夹紧表定值，判据在只有阈值表时不可算。本轮把它改写成台面上可读的量：

**κ=(k_cℓ²)/(k_dL²cos²θ)**，则 Ω=1/κ。环宽收缩 1−w 与 1/Ω 是同一个群的两条读数。

于是共同对象变成：一张夹紧表的三列——中心列（阈值平移，含 k_d 于二阶）、宽度列（κ，P 轴）、事件串/周期列（R 轴）。κ 不是第三轴，而是 P 轴的宽度坐标。

## 2. 关键推导与学习性算例（假设，未测）
pair_A：k_d=0.19 N/cm，k_c=0.07 N/cm，L=6.3 cm，k_dL²cos²θ≈6.66 N·cm/rad（θ≈20°，2 根耦合弹簧）。

| ℓ (cm) | κ=2k_cℓ²/6.66 | 实测 1−w（转子1/转子2） | 比例 (1−w)/κ |
|---|---|---|---|
| 1.577 | 0.052 | 0.056 / 0.059 | 1.07 |
| 3.154 | 0.209 | 0.167 / 0.176 | 0.80 |
| 4.731 | 0.470 | 0.361 / 0.353 | 0.77 |

两转子本征宽度差 4.2 倍（14.4 vs 3.4 cm），1−w 却一致到 2%：这是刚度比的性质，不是单转子属性。κ 的一阶读数是宽度列，不是阈值列（阈值列对 κ 只有二阶依赖）。

κ=1（支合并）落在 ℓ≈6.9 cm，几何上限 w/2=7.6 cm：现装弹簧下『推到极限』才刚接近沉默。若换 S007（0.07 N/cm）驱动弹簧，ℓ=4.731 单元 κ≈1.3 ⇒ 预测跳变关闭、环路消失，而释放 γ 几乎不动。

## 3. 条件性后果
1. **沉默不是新状态，是极限**：κ→1 时两支合并，γ→θ 单值，往返重描同一路径，不写入反转点。故它删除一个迟滞元素，而不是隐藏一段记忆；单独不破坏 R 轴（返回性）。
2. **三列分工**：阈值平移 ⇒ 中心列移动而宽度近似不变；环路关闭 ⇒ 宽度→0；次序反转 ⇒ 周期长度（T>1）。三种『该翻未翻』因此可分开读，前提是有夹紧表。
3. **非单调图结构**（新支）：κ 跨 1 会删边，故受挫回路的奇偶可被抹平；κ 略小于 1 的窄环单元则最易被同 γ 带走。『更强耦合＝更差记忆』不成立。
4. **network_C**：16 事件第 9–16 与第 1–8 逐项相同，只支持该幅值下事件串周期为 1；s3 的『该翻未翻』在无 γ 反转行、无时间戳的条件下，不能区分『阈值被推出幅值窗口』与『环路关闭』。
