# Data Repository

This repository contains the MATLAB (.mat) files with the experimental and numerical data supporting the figures presented in the article:

Alessandro Petrini, Claudio Conti, and Davide Pierangeli,
"Degree-of-polarization modulation for high-dimensional optical computing",
Nature (2026). https://doi.org/10.1038/s41586-026-10891-z 

The repository is organized according to the figures of the main manuscript and Supplementary Information. Each folder corresponds to a figure, and the MATLAB files are named according to the individual figure panels where applicable.

The repository includes both raw experimental measurements and processed data required to reproduce the results presented in the figures. 

For further information regarding the data organization or the reproduction of the figures, please contact the corresponding author.
