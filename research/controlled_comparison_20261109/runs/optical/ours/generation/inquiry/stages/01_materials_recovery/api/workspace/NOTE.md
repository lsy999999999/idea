# 光学偏振扫描：共同研究材料

## 观察与边界

- spread 扫描有 102 行。预览中，dphi 从 0 增至约 0.41 时，DOP 从约 93.14 降至约 31.00；完整 dphi 范围为 0 至约 0.505。数据字典将其称为相位分布宽度控制，但单位待原文核实。此为已提供测量，不是独立发现。
- mean_phase 扫描有 200 行，范围为 0 至 2π。预览 DOP 约 0.73–0.84，S1/S2/S3 随预览相位点变化。不能由预览断定完整趋势。
- 两扫描不是独立重复；DOP 导出标度不同（spread 约 0–100，mean_phase 约 0–1），不得合并原始值。不可假定 S 分量平方范数等于导出 DOP。

## 共同探索问题

1. spread 扫描中 DOP 随 dphi 增大而下降，这是否与相位分布变宽造成不同空间贡献相消相容？这只是条件性解释；测量定义、控制条件与论文机制均未核实。
2. mean_phase 扫描中，平均相位主要改变偏振方向，还是也系统改变偏振度？现有预览不能判定完整响应。
3. dphi 单位、DOP 定义、S 分量规范化、扫描顺序、汇总与误差来源分别是什么？这些问题会影响两扫描可比较到什么程度。

## 并列保留

- spread 分支：核实完整曲线及相位分布宽度与偏振统计之间的关系。
- mean_phase 分支：核实周期响应、方向分量与偏振度的关系。
- 不把条件性机制写成发表结论，也不将预览点视为独立重复。

## 学习与来源缺口

当前材料足以定位需要学习的概念：偏振度、Stokes 参数、相位平均及空间调制测量约定；但没有独立教材或综述，也没有原研究正文、方法和图注。不得据此补写定量预期或声称已读论文解释。后续取得这些材料后，记录逐字引文、适用条件与修订过的理解。
