# 波动情境：学习与共同提问记录

## 材料与观察

情境材料描述 111 个活跃机电单元构成的二维阵列，并给出 2199 个时间样本的空间相关宽度、宽度误差导出值、平均剪切幅值和归一化逆相关长度。预览中相关宽度总体随时间增大但有波动；剪切幅值在首个预览点之后大致相近。样本是实验聚合，不能视作 2199 次独立运行。

来源材料把空间粗化与时间结晶联系起来。这是情境中对已发表工作的描述，不是本次独立发现；论文原文未提供，故不推述其具体机制或论证。

## 期待及依据

一个待核对的定性期待是：若空间粗化伴随相关尺度增长，相关宽度可能总体增加、其倒数量可能总体下降。依据仅为情境材料中的“spatial coarsening”描述与变量定义；没有独立领域基础资料支持它成为已核实的理论预言，也不要求变化单调。

数据字典明确规定归一化量为 fwhm[1]/fwhm。相关宽度是长度代理，不能与倒数混称。归一化量的汇总值含 Infinity，不能解释为有限均值。

## 共同问题与保留分支

- 相关宽度与平均剪切幅值是否同步变化，或存在滞后？现有预览不足以判断。
- 表观时间趋势会否因宽度估计、图像处理或样本时间相关性而改变？
- 重复运行之间是否存在差异？当前没有运行标识，不能评估。
- 相关尺度变化是否与论文讨论的时间结晶机制有关？论文原文与足够的底层数据均缺失，保持未决。

这些分支并不互斥。聚合数据描述、发表解释和后续假说应分别保存；目前没有理由把相关性写成因果关系。

## 学习与来源边界

本次可用来源只有情境 dossier 和共同提问计划。计划提及 Nersessian 的概念形成研究以及 Star、Griesemer 的 boundary objects 研究，但提供的是二手概述，未提供可核验的原文。因此不把它们当作已读的独立领域基础资料。论文全文、原始摘要文本、measurements.csv、底层图像序列和重复运行标识也未提供。

后续学习应从可读取的论文原文及独立基础教材或综述开始，并保存实际下载文本、URL、访问状态及逐字引文。若补得原始测量资料，再检查估计定义、时间依赖及运行间变异。
