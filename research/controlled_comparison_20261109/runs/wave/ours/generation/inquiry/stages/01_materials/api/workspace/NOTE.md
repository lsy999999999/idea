## 情境与证据边界

提供的 brief 指向论文 *Wave coarsening drives time crystallization in mechatronic metamaterials*，并称研究对象为二维阵列中的 111 个活跃机电单元。brief 提供 2199 个时间样本的摘要统计和少量预览，不等于论文全文或原始数据。样本是导出的实验聚合，而非独立重复运行；原始图像、运行标识和误差聚合细节均缺失。

论文讨论空间粗化属于来源论文的既有解释，不是本次发现。当前语料不足以核验作者的具体机制、论证或适用范围。

## 观察、期待与依据

- **观察（提供的数据摘要）：** 预览中的相关宽度从 0 秒约 1.50，至 7.33 秒约 15.05；中间存在起伏。剪切幅值首个点约 0.046，其余预览点大致在 0.147–0.187。少量预览不能代表完整序列的统计检验。
- **条件：** 时间范围 0–7.3267 秒，300 样本/秒。`correlation_width` 是空间相关长度代理。归一化逆相关长度严格定义为 `fwhm[1]/fwhm`，不能把长度与倒数混淆。
- **期待（待核对）：** 若“空间粗化”对应相关尺度增长，宽度可能总体增加、其倒数量可能总体下降；不要求单调，也没有材料支持剪切必须同步变化。
- **依据及假设：** 该期待仅依据 brief 对粗化的描述和数据字典定义。没有独立教材或综述支撑，故不将其写成已建立的理论预言。

## 解释分支与未决问题

1. **作者解释：** brief 称作者讨论空间粗化并联系时间结晶。具体论证待取得论文文本核验。
2. **估计与聚合分支：** 宽度波动可能与估计方法或实验聚合有关；现有材料不足以判断。
3. **尺度与动力学分支：** 剪切和相关宽度可能有不同时间响应或滞后；预览不足以区分。
4. **可共同追问的问题：** 在剪切幅值预览值大致相近的区间，相关宽度仍有变化。这种关系是否稳健，还是受估计误差、时间相关性或未记录的重复运行差异影响？该问题是条件性提问，不暗示因果或已发现机制。
