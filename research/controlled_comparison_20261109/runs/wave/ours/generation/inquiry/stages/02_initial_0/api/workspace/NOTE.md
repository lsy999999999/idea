# 初步理解与共同问题

## 材料与边界

情境材料描述一个由 111 个活跃机电单元组成的二维阵列，给出 2199 个时间样本的相关宽度代理、宽度误差导出值、平均剪切幅值及按来源笔记本定义的归一化逆相关长度。时间范围为 0 至约 7.327 秒，采样率为每秒 300 个样本。情境明确说明这些是实验聚合的时间样本，不是 2199 次独立实验。

可见预览中相关宽度总体从早期较小值升至后期较大值，但并非单调；剪切幅值在首个预览点后大致处于相近范围。这只是预览点之间的描述，不能代替全序列分析。情境所称“空间粗化并联系时间结晶”属于已发表研究方向，不作为本轮发现。

相关宽度是空间相关长度代理；归一化逆相关长度严格定义为 `fwhm[1]/fwhm`，不能与长度本身混称。其汇总统计含 Infinity，因此不能把该列的均值当作有限数值解释。

## 学习与 worked example

本轮能够从材料核对的基本关系是：若长度代理 `L` 增大，其倒数 `1/L` 减小；例如仅作概念演示，`L=2` 时 `1/L=0.5`，而 `L=10` 时 `1/L=0.1`。这说明“相关长度增加”和“逆相关长度下降”可描述同一尺度方向，但归一化因子 `fwhm[1]` 及零值处理会影响具体数值；本例不是对来源数据的重新计算，也不代表幂律拟合。

尚不能解释或使用：来源中 `fwhm` 的图像处理细节、`ste` 的统计定义，以及该系统时间结晶的具体物理机制。现有语料未提供可直接阅读的独立波动物理基础来源，因此不声称已补齐专业基础。

## 概念缺口与条件性分支

焦点是相关尺度增长与平均剪切幅值之间缺少明确的动力学联系。平均剪切幅值是一个汇总量，相关宽度则表征空间尺度；仅凭两条预览序列，不能判断前者是驱动、响应、滞后变量，还是彼此独立的量。

**假说分支：** 若平均剪切幅值表征驱动相关结构演化的活动状态，而相关宽度表征空间响应尺度，那么剪切变化可能先于或滞后于宽度变化。若该关系成立，单一时刻的剪切值未必能刻画当前粗化尺度；可能需要把动力学历史与空间响应分开描述。反之，若二者解耦，则粗化尺度不能由剪切幅值单独刻画。

**替代分支：** 宽度起伏也可能主要源于估计与聚合方式、时间相关性或未记录的运行差异；在这种情况下，表观宽度—剪切关系不必代表新的物理耦合。两个分支都没有被当前材料证实或排除。

### 具体问题

在完整时间序列及其测量定义明确后，相关宽度的变化相对于平均剪切幅值的变化是否有稳定的先后关系？若有，它体现的是剪切活动作为尺度演化的先行量，还是共同受未表征的系统状态驱动？

## 学习计划与来源类别

本轮实际阅读的波动物理材料只有情境简报及数据字典，属于直接情境资料，不是独立基础来源。持续学习计划是学习流程的方法材料，不能支持波动物理结论。没有取得新的外部来源或可阅读的独立基础资料。

需补的具体知识连接是：在非平衡活性系统中，局部或平均剪切活动如何与空间相关尺度的时间演化相联系；厘清这一点可能改变我们把剪切看作尺度驱动、响应还是独立观测量的方式。回到这一缺口后，当前仍只能提出条件性关系，不能判断哪一支成立。
