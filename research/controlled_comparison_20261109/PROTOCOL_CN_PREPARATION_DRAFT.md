# 科研 agent 对照准备：统一资源，暂不调用模型

2026-11-09。当前状态：准备阶段，未启动本次模型推理、训练或服务器任务。用户最新要求优先于此前完整复现请求：等接入 DeepSeek 后，以接近的资源消耗比较。既有四套系统的小试跑不混入本次结果。

## 比较对象与边界

我们的 learning-inquiry-v3／hypothesis-cycle-v1，对照 ResearchAgent、Virtual Lab、AI Scientist-v2、EvoScientist。先固定本地已有官方代码版本，再核查论文配置与实现对应；EvoScientist 的应用代码不直接等同于论文三角色、两类记忆的实验实现。

保留每套系统原生的主要机制：ResearchAgent 的问题/方法/实验与评审；Virtual Lab 的团队、个别会议和批评角色；AI Scientist-v2 的构思、四阶段实验搜索、纠错与报告；EvoScientist 的规划、研究、代码、调试、分析、写作及记忆。逐系统记录实际运行与缺失环节。固定预算用尽后未完成的流程记为 budget_exhausted，不声称完整论文复现或达到其最好效果。

本轮目标是“相同资源下的表现”。原论文最强配置往往使用不同模型、算力或实验条件，其最好效果不能与这一目标同时保证。模型、论文场景和预算均变化时，结论描述为受控迁移对照。

## 统一条件

1. DeepSeek 的精确模型 ID、版本/日期、接口、推理模式一致；目前均待确认。所有研究、评审、子任务和内部模型调用计入系统总账，不能混用 Luna 隐性补充。
2. 两个理工科案例；每系统每案例一次主运行。单次结果用于具体行为分析，不推断总体胜率。
3. 原始数据、单位、实验条件、可见知识、检索库版本相同，输入文件按哈希固定。准备公共数据概览，保留原始文件；对不支持直接执行的系统明确标注能力边界。
4. 主实验隐藏目标论文的解释与结论，保留必要数据来源/许可。文件名、说明文档、检索结果可能泄露结论，逐项登记；无法隔离时标为“已知论文背景下的延伸研究”，不声称盲重发现。
5. 每套系统、每个案例使用隔离工作目录与记忆；主比较从空任务记忆开始，保留学科身份和角色设定。既有葡萄酒/电池记忆不单独提供给我们。每套系统都可在本次运行内积累自己的记忆。
6. 在同一台机器、相同 CPU/内存/并发与执行限制下比较。优先使用用户先前指定的服务器；正式运行前核验可用资源。先采用 CPU 数据分析预算，不默认启动昂贵训练。GPU 若必要，应对所有系统开放相同额度并单列。

## 资源账本

预算是上限，不要求无意义消耗到上限。配置中的数值是可调整草案，不是已产生的消耗或费用估算。正式运行前根据 DeepSeek 接口和一次小型兼容检查冻结。

- 分别统计输入 token、输出 token、缓存命中/未命中及服务返回的推理 token；推理 token 若已包含在输出总数内，不重复相加。
- 记录全部调用、失败与重试、每阶段累计消耗、运行时间、CPU core-seconds、GPU-seconds、峰值内存、检索/计算工具次数及返回文本量。
- 统一输入/输出额度及工具/计算上限；实际资源相差超过 10% 时，展示预算进度检查点或明确差异，不直接声称等消耗。
- 等调用次数不等于等资源，等总 token 也不等于等费用；成本只能按该模型服务真实费率和缓存情况计算。
- 独立最终评价另列成本，并对每系统提供相同评价额度。为单个系统手工补充的检索、修改和计算都进入干预记录，不能作为系统自主表现。
- 账本/预算拦截器尚待接入各系统，当前配置不能单独保证限额。

## 两项任务

**提出问题与假说。** 保存每套系统的原始候选、分支、假设、条件性推论、所依据的观察，以及讨论前后的内容变化。允许不完整方向；不以证明、现成数据、可实施性为保留条件。记录新关系、新应用、纠正、澄清、重述或未决，不只汇总打分。

**纠错。** 主生成运行先冻结，再用独立任务副本、同样额外预算进行标准化错误诊断。所有系统收到同一份审计材料，其中包含预先登记的错误与正确对照项。错误可涉及单位、数组轴/分组、比较对象、因果/预测解释错位；以可独立复算的错误为主。人工注入明确记在控制端答案表，不能称为原论文错误。分别记录发现、定位、修正、复核、误报，以及修正后假说是否被合理调整。主生成中的自然错误另外统计，不与注入错误混算。

错误材料与答案在正式输入冻结前尚未制作；目标论文自身的编辑注记不等同于已经查明具体错误。

## 最终交付

每案例列出原论文/数据来源及可见范围；每系统列实际配置、消耗、完成度、最后提出的具体问题/假说、纠错明细、未决点和人工介入。新颖性与明显数学/逻辑错误分别检查。系统身份隐藏后的复核与可复算证据并列，模型评语不当作客观真值。

当前仅有候选来源与运行配置草案；尚无新实验结论。
