# 科研接口修复与验收 · 2026-11-09

已修复这次实验的 API 适配层：重复上下文改为原文引用，开放真实文献补学和完整 CSV 计算，并补上来源交接、工具回传和提交校验。原实验及工作树中的科研控制器未重写。本次验收是接口测试，不是新的系统优劣比较。

**1．压缩重复输入**

原文按内容哈希保存一次，嵌套的 before_inputs、development_cycle.sources 和研究输出用短文档编号引用。保留原始文本、来源、哈希和分页入口；模型可按文档编号或 JSON 字段读回。没有用摘要替换科学论述。

用上次卡住的光学内审材料实测，最终版本将首轮材料从 **184,271 降为 15,439 token，减少 91.62%**。这包括直接给齐四份必读研究输出，避免逐份读取的额外模型往返。交流材料从 18,715 降为 3,378 token，减少 81.95%。分词器为 o200k_base，数值不含系统提示、工具定义及后续对话。[测量记录](../interface_repair/COMPRESSION_FINAL.json)。

初版仅放引用时为 7,735 token、减少 95.80%，但真实运行显示：逐份读取会产生更多往返，并重复携带先前历史。因此最终采用“必读输出预装 + 历史按需读取 + 多份材料批量读取”。**91.62% 是首轮材料缩减，不是整轮费用降幅。** 普通无状态 API 的后续请求仍需携带必要历史；服务端缓存是否命中由服务实际返回，不承诺免费。

**2．修复的接口问题**

- read_document / read_documents：原文、字段和分页读取；可一次读最多 8 个文档页，总计最多 24,000 字符。
- analyze_csv：真正读取完整注册 CSV，执行模型自己提出的受限数值表达式，返回总行数、筛选行数、文件哈希和结果。大数组按编号保存，不冒充完整预览。
- search_sources：通过 Europe PMC、Crossref、OpenAlex 实际检索，保存可读内容、URL、访问深度和失败原因；摘要不会标成全文。当前并非任意网站浏览器。
- 来源交接：支持短文档编号，转换到精确的现存文件，避免抄长路径漏扩展名；source_use 使用实际补学回复编号。
- 提交：一次反馈所有通用字段错误；内审反馈指出引文实际所在阶段和可用记忆编号；原生的研究状态、假说、补学和内审校验仍保留。无效结果不写入研究记忆。
- 文件：声明的产物必须真实存在或在提交时写入；空产物列表会保存作者原样 summary，明确标记为接口生成的文件，不补写科学内容。
- 传输：修复 Responses 工具回传中的 SDK 字段别名，保留工具 call_id 和推理状态；支持 Chat / Responses 两种传输，仍可换模型与地址。
- 运行：研究记忆与新运行目录分离；生成和纠错分别存储；保存会话和工具缓存；冻结账户禁止续写；模型、配置或适配代码变化会阻止混用旧阶段。
- 新建复跑：默认在线补学，可显式选 closed；只更新新副本的访问策略，避免“工具开放但案卷仍禁止联网”的矛盾。旧测量数据逐字节不变，旧运行和记忆不复制。
