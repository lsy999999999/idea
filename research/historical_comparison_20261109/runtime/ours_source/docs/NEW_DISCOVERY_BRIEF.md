# 新一轮探索任务模板

目标：构建新的研究 idea。寻找一个值得研究的问题、概念联系、机制假说或问题表述，说明它想改变什么、为什么有价值。当前不要求解决这个问题，也不以能否立即验证作为保留条件。

本轮没有预设正确答案或变量菜单。已有概念可作为跨域启发，候选可以保留尚未解决的核心问题。说明 idea 的研究方向和关键思路即可；公式、实现、数据和实验计划均为可选。

由最终 check agent 检查两项：比较已有工作对核心贡献的覆盖，单列方向重合，并按实验控制端的时间与来源可见性记录判断任务内新颖性；数学上只排查明显算术、方程、量纲或逻辑错误。来源论文被隐藏时，独立提出相同 idea 可以记为重发现；后续文献不否定历史新颖性。大方向说得通就通过数学粗筛。按 `IDEA_CHECK.md` 保存来源和简短判断，无需执行验证实验。

已有工作只有在任务中明确列出时才作为起点；否则先自主搜索新的研究情境。若要延续上一轮，请在这里补充需要读取的报告路径和仍未解决的问题。

运行目录由命令指定；只在本次运行目录保存新材料。最终交付中文 idea 说明及每个 idea 的两项检查结果，原始候选全部保留。

检索暂未找到相近工作时，写“暂未找到”；检索不足时，写“检索不足”。
