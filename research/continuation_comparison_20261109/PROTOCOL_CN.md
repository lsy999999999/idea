# 本轮实际执行口径

2026-11-09。用户要求现在用 GPT-6、保留可替换 API，并控制费用。本轮使用已有授权服务，请求 GPT-6 Luna / low；全部成功响应报告同一模型名。后台调用现已停止。

每系统每案例生成阶段上限：640,000 输入 token、45,000 输出 token、96 次调用；单独纠错阶段：90,000 输入、8,000 输出、14 次调用。限额是共同上限，不是相同实际消耗。失败调用计入次数；未返回 usage 的消耗未知，不估计第三方收费。

最初的字节数预估会提前拦截。随后改为 o200k_base 分词加 10% 和 256 token 的预留，并对 ResearchAgent/EvoScientist 纠错重试，相同请求复用已存响应。服务分词规则和失败请求计费无法由本工具确认，因而限额属于请求前估算及响应后结算，不能声称绝对费用硬上限。最终账本与所有成功原始响应逐项核对。

使用两份 Nature 公开图表源数据，论文身份和解释可见。外部文献检索关闭，隔离各系统任务目录和记忆。ResearchAgent/Virtual Lab/ours 的本轮 API 角色只读取案卷和 12 行预览；AI Scientist-v2/EvoScientist 可以读取、计算完整 CSV。因此数据访问和工具能力尚未完全对齐。

ResearchAgent 保留问题/方法/实验三阶段各三轮及五维评审，参考文献/实体构建被共同案卷替代。Virtual Lab 保留团队会议、个别会议、批评与综合。AI Scientist-v2 使用官方构思及 MinimalAgent 的四个实现/纠错/改进节点，CPU 运行；没有完整 BFTS、VLM、论文撰写。EvoScientist 为固定官方应用版本，不能等同于论文全部记忆实验。Ours 调用最新 learning-inquiry-v3 控制器的独立源码副本，保留问题/假说/记忆/交流/内审交接；未增加 portfolio 发展期。

本机运行讨论与 EvoScientist；AI Scientist-v2 在优先服务器 10.42.127.214 的既有环境，4 CPU 线程，无 GPU 训练。工具与 CPU 限制主要通过任务提示和执行超时实现，未实现统一操作系统级资源隔离。

纠错是独立工作目录里的预置错误备忘录，不是指控原论文存在这些错误。只执行了机械案例 W1–W4；光学 O1–O4 仅准备、未调用。部分审计与主生成并行，输入、记忆、响应均隔离；未将审计答案返回主生成。最终人工记录核对在主运行结束后进行，没有盲评或外部新颖性审查。

两次我们流程中的格式干预：光学案例额外说明固定语料不可检索、broker 来源分类规则；API 解析器允许去除一个完整 JSON 对象后多余的闭合括号，保留原始回复及修复标记，未改科学字段。其他引用/内容校验保持原样，失败与资源中止均保留。

具体结果见 RESULTS_CN.md；所有实际资源见 SUMMARY.json；后续换模型使用 API使用说明.md，创建新目录，保留本轮历史。
